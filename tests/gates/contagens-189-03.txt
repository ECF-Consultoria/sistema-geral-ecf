# ⚠️⚠️ O QUE ESTE ID MEDE, E O QUE PRECISARIA ESTAR ERRADO PARA ELE FALHAR:
#   1. ⚠️⚠️ **`moverNoLightbox` "unificado" com a navegação do PAINEL**, que
#      CLAMPA (`:1018`, 188-07). O lightbox DÁ A VOLTA (`:1321`), e a asserção
#      **RECUSA explicitamente o `0`** que um clamp devolveria em
#      `moverNoLightbox(0, -1, 5)` — é a isca que distingue INVERSÃO de TROCA DE
#      NÚMERO, não um valor decorativo;
#   2. `indiceNoLightbox` devolvendo `0` em vez de `null` com total `0`: o `null` é
#      o que FECHA o lightbox (`:1324`), e um `0` deixaria a casca de tela cheia
#      aberta **sobre nada** — e reprovar uma foto TIRA ela do conjunto final;
#   3. ⚠️ `origemDoZoom` dividindo por `width` `0` (dá `Infinity`) ou deixando
#      passar `NaN`. ⚠️ `typeof NaN === 'number'`: guarda por `typeof` desenharia
#      `transformOrigin: 'NaN% NaN%'`, que **não lança** e é o caminho da TELA
#      PRETA (voltou SEIS vezes, a última NO CLIQUE). Há **isca do mesmo lado**:
#      a MESMA forma com tipos certos PRODUZ origem — sem ela, "caixa inválida →
#      null" seria satisfeito por uma função que devolve `null` sempre;
#   4. ⚠️⚠️ **GATE-09** — `duration-[150ms]`, `delay-[…]` ou `ease-[…]` na fonte:

#      transição sairia SEM duração, com todo render passando. O controle é

#      que as QUATRO regexes VEJAM as formas erradas.
#      ⚠️⚠️ **E a leitura é SEM COMENTÁRIO**: o docblock do `.jsx` CITA as três
