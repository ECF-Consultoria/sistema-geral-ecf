#                    guarda de `test -e` do topo lança antes de registrar teste

#   · 113          — Task 1 verde (só os módulos).

#                    componente ainda ausente.
#   · 180          — Task 2 verde, com o bloco de CSS construído.

# DOIS REGIMES (GATE-10), os dois MEDIDOS nesta máquina:
#   180 = CSS construído mais NOVO que os três `.jsx` (logo após `npm run
#         build`): o bloco "GATE-02 (CSS)" roda inteiro, com os seus 11

#         11 subtestes consigo (180 − 169 = 11), com `# skipped 1` no lugar.
