# Funcionamento do Investimento Mensal

O valor do investimento é definido com base no faturamento mensal obtido pelo cliente no Mercado Livre. Conforme o faturamento aumenta, o investimento mensal é ajustado para acompanhar o volume da operação e o acompanhamento estratégico realizado.

## Tabela de Investimento

| Faturamento Mensal (Mercado Livre) | Investimento Mensal | Equivalência aproximada sobre o faturamento |
|-------------------------------------|---------------------|---------------------------------------------|
| Até R$ 499.999,99 | R$ 3.000,00 | — |
| De R$ 500.000,00 até R$ 999.999,99 | R$ 4.500,00 | 0,9% – 0,45% |
| De R$ 1.000.000,00 até R$ 1.999.999,99 | R$ 6.000,00 | 0,6% – 0,3% |
| De R$ 2.000.000,00 até R$ 2.999.999,99 | R$ 7.500,00 | 0,37% – 0,25% |
| De R$ 3.000.000,00 até R$ 3.999.999,99 | R$ 9.000,00 | 0,3% – 0,225% |
| De R$ 4.000.000,00 até R$ 4.999.999,99 | R$ 10.500,00 | 0,26% – 0,21% |
| Acima de R$ 5.000.000,00 | A partir de R$ 12.000,00 | Aproximadamente 0,24% |

## Exemplos Práticos

- Se o cliente faturar **R$ 320.000,00** no mês → investimento mensal de **R$ 3.000,00**.
- Se o cliente faturar **R$ 700.000,00** no mês → investimento mensal de **R$ 4.500,00**.
- Se o cliente faturar **R$ 1.500.000,00** no mês → investimento mensal de **R$ 6.000,00**.
- Se o cliente faturar **R$ 2.400.000,00** no mês → investimento mensal de **R$ 7.500,00**.
- Se o cliente faturar **R$ 3.800.000,00** no mês → investimento mensal de **R$ 9.000,00**.
- Se o cliente faturar **R$ 4.300.000,00** no mês → investimento mensal de **R$ 10.500,00**.
- Se o cliente faturar **R$ 6.000.000,00** no mês → investimento definido a partir de **R$ 12.000,00**.

## Observação

O investimento acompanha o crescimento da operação, mantendo proporcionalidade entre o faturamento do cliente e a gestão estratégica realizada.
