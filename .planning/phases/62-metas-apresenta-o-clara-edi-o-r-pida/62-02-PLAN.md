## Shape das props (contrato do componente)

```
GoalProgressPanel({
  goal: {
    id: number,
    metric: string,                     // e.g. 'revenue', 'tacos', 'nps'
    metric_label: string,               // e.g. 'Faturamento', 'TACOS'
    target_value: string|number,        // decimal com 2 casas do backend (Goal::$casts)
    value_type: 'currency' | 'percentage' | null,
    period_type: 'monthly' | 'quarterly' | 'yearly',
  },
  results: [                            // Últimos até 12 GoalResult ordenados ASC por period
    {
      id: number,
      period: string,                   // 'YYYY-MM' (formato Goal::hasMany results)
      realized_value: string|number,
      target_value: string|number,      // snapshot na hora do cálculo (Model GoalResult)
      achieved: boolean,
    },
  ],
  compact?: boolean,                    // default false — modo compacto para grid do Goals/Index (chart menor)
  className?: string,
})
```

## GoalResult.LOWER_IS_BETTER (JS constant obrigatória — espelhar do PHP)
```
const LOWER_IS_BETTER = ['tacos', 'acos', 'absenteeism', 'products_without_cost'];
```
Para métricas `LOWER_IS_BETTER`, "melhor" = menor. Delta = `(target - realized) / target * 100`. Para as demais, delta = `(realized - target) / target * 100`.
