<design_margem_placeholder>
<!-- DECISÃO DE DESIGN TRAVADA — implementar exatamente assim (não reinventar). -->

Invariante inegociável: profissional SÓ-performance (nenhuma empresa Shopee)
tem nota_final, pontos_componentes.margem e score_status IDÊNTICOS aos de hoje.

Regra da dimensão margem (pontos que entram na nota):
  margemPontos(?float $varMargemReal, int $nComMargemReal, int $nShopeePlaceholder):
    pReal = reguaMargem($varMargemReal)   // null se varMargemReal null
    numerador   = (pReal !== null ? pReal * nComMargemReal : 0.0) + 1.0 * nShopeePlaceholder
    denominador = (pReal !== null ? nComMargemReal : 0) + nShopeePlaceholder
    return denominador > 0 ? round(numerador/denominador, 2) : null

  - nComMargemReal = nº de empresas que contribuíram para varMargemReal (empresas Adman com diff de margem não-null).
  - nShopeePlaceholder = nº de empresas elegíveis cuja fonte é 'shopee'.
  - Só-performance (nShopeePlaceholder=0) → margemPontos = reguaMargem(varMargemReal) → IDÊNTICO a hoje. ✓
  - Só-Shopee (nComMargemReal=0, pReal=null) → margemPontos = 1.0. ✓
  - Misto → blend ponderado por contagem (margem=1 puxa a média proporcionalmente). ✓

computeVarMargem: continua devolvendo a % real (média dos diffs Adman) para
`componentes.var_margem_pct` — NÃO misturar placeholder no pct exposto.

computeNotaFinal: passar a receber `margemPontos` já calculado (em vez de chamar
reguaMargem internamente). pontos_componentes.margem = margemPontos.

computeScoreStatus: trocar o parâmetro varMargem por margemPontos:
  partial se varFat===null || margemPontos===null.
  → só-Shopee (margemPontos=1.0) não é partial; blocked segue só quando
    vinculos_financeiros===0 (que Shopee agora NÃO é mais — logo só-Shopee sai de blocked).

Faturamento: computeVarFaturamento roteia por fonte via dispatcher; empresa
Shopee devolve revenue.diff_pct (Shopee tem faturamento) e entra na média
normalmente (não precisa placeholder).
</design_margem_placeholder>
