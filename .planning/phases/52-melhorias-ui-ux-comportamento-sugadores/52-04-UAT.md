## Rodada 1 — hotfix ReferenceError

Após deploy inicial, operador reportou `/sugadores` em branco (sem erro visível).

**Root cause:** `Index.jsx` linha 33 tinha `const TIPO_ICONS = { adgroup: Tag, campanha: Megaphone }`. `Megaphone` NÃO estava importado de `lucide-react`. Wave 2 removeu tudo que consumia `TIPO_ICONS/TIPO_LABELS` mas deixou a declaração top-level. `ReferenceError` na avaliação do módulo — Inertia não renderiza boundary com erro de módulo → tela branca.

**Fix** (commit `d81bafa`): remover `TIPO_ICONS` + `TIPO_LABELS` (código morto pós-Wave 2) + remover `Tag` do import (não usado). Redeploy OK.
