**Passo 1 (linha ~309):** Ao carregar o survey, adicionar `template` na string de eager-load:

Antes:
```php
$survey = NpsSurvey::with(['company', 'generatedBy'])
    ->where('token', $token)
    ->firstOrFail();
```

Depois:
```php
$survey = NpsSurvey::with([
        'company',
        'generatedBy',
        'template.questions.options',  // Phase 71 Plan 01 — v15.0 form dinâmico
    ])
    ->where('token', $token)
    ->firstOrFail();
```

**Passo 2 (imediatamente antes do `return Inertia::render(...)` na linha ~364):** Montar o array de `template` para o front — APENAS SE `$survey->template_id !== null` e `$survey->template` presente.

Adicionar bloco:
```php
// ─── Phase 71 Plan 01 — Payload dinâmico v15.0 ────────────────────────
// Se o survey tem template associado (Phase 68/69), monta o shape que o
// PreviewFormulario.jsx do Phase 70-05 consome — Respond.jsx importa esse
// componente puro identico e envolve com submit hook.
//
// Surveys sem template_id (legacy pre-migration ou dispatch quebrado) recebem
// $templatePayload=null — Respond.jsx cai no fluxo Phase 33 (form fixo com
// perguntas legadas + perguntas_extras).
$templatePayload = null;
if ($survey->template_id !== null && $survey->template) {
    $templatePayload = [
        'id'        => $survey->template->id,
        'nome'      => $survey->template->nome,
        'descricao' => $survey->template->descricao,
        'perguntas' => $survey->template->questions->map(function ($q) {
            return [
                'id'          => $q->id,
                'ordem'       => $q->ordem,
                'texto'       => $q->texto,
                'tipo'        => $q->tipo,
                'dimensao'    => $q->dimensao,
                'obrigatoria' => $q->obrigatoria,
                'options'     => $q->options->map(fn ($o) => [
                    'id'    => $o->id,
                    'ordem' => $o->ordem,
                    'label' => $o->label,
                    'peso'  => $o->peso,
                ])->values()->all(),
            ];
        })->values()->all(),
    ];
}
```

**Passo 3 (linha ~364):** Adicionar `template` na chave de props do Inertia::render (preservar todas as chaves legacy):

Antes:
```php
return Inertia::render('Nps/Respond', [
    'survey' => [...],
    'perguntas_extras' => $perguntasExtras,
]);
```

Depois:
```php
return Inertia::render('Nps/Respond', [
    'survey'   => [
        'token'              => $survey->token,
        'company_name'       => $survey->company->name,
        'estrategista_name'  => $estrategistaNome,
        'analista_name'      => $analistaNome,
        'tem_analista'       => $temAnalista,
        'textos'             => $textosRender,
    ],
    'perguntas_extras' => $perguntasExtras,
    'template'         => $templatePayload,  // Phase 71 — dinâmico v15.0 (null em legacy)
]);
```

**IMPORTANTE:** NÃO remover as props legacy (`survey.textos`, `perguntas_extras`). Elas continuam sendo enviadas — Respond.jsx (Plan 71-02) decide o path pela presença de `template`.
