<objective>
W1 do Phase 30 — Throttled queue Adman + checkpoint de paginação completa.

Resolver causa raiz dos dois primeiros problemas em prod:
1. **429 Adman**: 2 workers concorrentes furam o throttle interno (`usleep 6.5s`) e batem o hard limit de 10 req/min/key. Fix: rate limiter GLOBAL distribuído (cache Redis) via middleware `RateLimited('adman-api')` aplicado a todos os Jobs Adman.

Purpose: Prod estável pra Sugadores em contas grandes (Adman path mantém compatibilidade total com Bymobile teste / W2). Valida pattern de throttle distribuído reusável em Milestone v10.0.
Output: Rate limiter global registrado, 2 Jobs com middleware, checkpoint de paginação, suíte Feature.

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-30-01 | Denial of Service | RateLimiter 'adman-api' bucket | mitigate | Bucket 'global' faz com que workers distribuam carga; cap de 10 re-dispatches previne loop infinito |

| T-30-04 | Tampering | re-dispatch via construtor | accept | `mlbsAcumulados` é trafegado via payload da fila Laravel (database driver); workers internos confiáveis, não há superfície externa |
