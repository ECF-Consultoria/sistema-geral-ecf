<research_reference>
Escolha de cor:
- Sistema usa `bg-ecf-yellow` para primary; `red-*` para destrutivo; `green-*` para success
- `orange-*` está disponível no Tailwind default e é semanticamente correto para "aviso — precisa ação"
- Evita confusão com `red-*` (usado para erros/destroy) e `yellow-*` (usado para primary CTA)

UX: dias_atraso
- 0 dias: mostra "hoje" (sutil)
- 1-3 dias: mostra "N dias" (atenção)
- >= 7 dias: mostra "N dias" + cor mais forte (crítico)

Trade-off — link do badge:
- Idealmente linkaria para `/nps/{token}` mas o token só é gerado no disparo mensal (comando `nps:disparar-mensal`)
- Se a survey do mês foi disparada mas não respondida: badge mostra "aguardando resposta"
- Se a survey do mês nunca foi disparada: badge mostra "não disparado"
- **Simplificação v15.0:** badge/widget SEMPRE linka para `Companies/Show` da empresa (histórico + botão "Disparar NPS manual" — funcionalidade futura Phase 73 ou v15.1)

Zero jargão técnico (memória feedback_evitar_jargao_ui):
- Badge: "NPS pendente" (visível ao usuário admin/consultor — pode usar termo NPS)
- Widget título: "Empresas pendentes de NPS este mês"
- Dias atraso: "há 3 dias" (natural em pt-BR)

```jsx
import { AlertCircle } from 'lucide-react';
import { cn } from '@/lib/utils';

/**
 * NpsPendingBadge — Phase 72 Plan 03 v15.0.
 *
 * Badge compacto usado em listagens de empresas (Portfolio/Show, Companies/Index).
 * Renderiza APENAS se companyId está na lista `pendentes` — do contrário retorna null.
 *
 * Props:
 *  - companyId (int): id da empresa a verificar
 *  - pendentes (array): shape do NpsPendingService::forCarteira (Plan 72-01)
 *  - variant ('inline' | 'compact'): 'inline' mostra texto; 'compact' só ícone
 */
export default function NpsPendingBadge({ companyId, pendentes = [], variant = 'inline' }) {
    const pendente = pendentes.find(p => p.company_id === companyId);
    if (!pendente) return null;

    const critico = pendente.dias_atraso >= 7;

    const tooltip = pendente.dias_atraso === 0
        ? `NPS pendente hoje (template: ${pendente.template_nome})`
        : `NPS pendente há ${pendente.dias_atraso} ${pendente.dias_atraso === 1 ? 'dia' : 'dias'} (template: ${pendente.template_nome})`;

    if (variant === 'compact') {
        return (
            <span
                title={tooltip}
                className={cn(
                    'inline-flex items-center justify-center w-5 h-5 rounded-full border',
                    critico
                        ? 'bg-orange-500/30 text-orange-300 border-orange-500/40'
                        : 'bg-orange-500/20 text-orange-400 border-orange-500/30'
                )}
            >
                <AlertCircle className="w-3 h-3" />
            </span>
        );
    }

    return (
        <span
            title={tooltip}
            className={cn(
                'inline-flex items-center gap-1 px-2 py-0.5 rounded-md border text-[11px] font-medium',
                critico
                    ? 'bg-orange-500/30 text-orange-300 border-orange-500/40'
                    : 'bg-orange-500/20 text-orange-400 border-orange-500/30'
            )}
        >
            <AlertCircle className="w-3 h-3" />
            NPS pendente
        </span>
    );
}
```

```jsx
import { Link } from '@inertiajs/react';
import { AlertCircle, Clock } from 'lucide-react';
import { cn } from '@/lib/utils';

/**
 * NpsPendingWidget — Phase 72 Plan 03 v15.0.
 *
 * Card com lista de empresas pendentes de NPS no mês corrente.
 * Consome shape do NpsPendingService::forCarteira (Plan 72-01).
 *
 * Props:
 *  - pendentes (array): shape do service
 *  - title (string, opcional): default "Empresas pendentes de NPS este mês"
 *  - maxVisible (int, opcional): default 5 — mostra "Ver todas" quando ultrapassar
 */
export default function NpsPendingWidget({
    pendentes = [],
    title = 'Empresas pendentes de NPS este mês',
    maxVisible = 5,
}) {
    if (!pendentes || pendentes.length === 0) {
        return (
            <div className="bg-ecf-card border border-white/[0.08] rounded-2xl p-5">
                <h3 className="text-white text-sm font-semibold mb-1">{title}</h3>
                <p className="text-white/40 text-xs">Nenhuma empresa pendente — todas responderam este mês.</p>
            </div>
        );
    }

    const visiveis = pendentes.slice(0, maxVisible);
    const restantes = pendentes.length - visiveis.length;

    return (
        <div className="bg-ecf-card border border-white/[0.08] rounded-2xl p-5">
            <header className="flex items-center justify-between mb-3">
                <h3 className="text-white text-sm font-semibold">
                    {title}
                </h3>
                <span className="inline-flex items-center gap-1 px-2 py-0.5 rounded-md bg-orange-500/20 text-orange-400 border border-orange-500/30 text-[11px] font-medium">
                    <AlertCircle className="w-3 h-3" />
                    {pendentes.length}
                </span>
            </header>

            <ul className="space-y-2">
                {visiveis.map(p => (
                    <li key={p.company_id}>
                        <Link
                            href={route('companies.show', p.company_id)}
                            className={cn(
                                'flex items-center justify-between rounded-lg px-3 py-2 border transition-colors',
                                'bg-white/[0.03] border-white/[0.08] hover:bg-orange-500/10 hover:border-orange-500/20'
                            )}
                        >
                            <span className="text-white text-sm truncate mr-3">{p.name}</span>
                            <span className="inline-flex items-center gap-1 text-orange-300 text-[11px] whitespace-nowrap">
                                <Clock className="w-3 h-3" />
                                {p.dias_atraso === 0 ? 'hoje' : `há ${p.dias_atraso} ${p.dias_atraso === 1 ? 'dia' : 'dias'}`}
                            </span>
                        </Link>
                    </li>
                ))}
            </ul>

            {restantes > 0 && (
                <p className="text-white/40 text-xs text-center mt-3">
                    + {restantes} {restantes === 1 ? 'outra empresa pendente' : 'outras empresas pendentes'}
                </p>
            )}
        </div>
    );
}
```
