<objective>
Trocar a fonte de dados do módulo `/grants` (admin) do pipeline frágil **XLSX-via-SFTP** para a API HTTP do **ECF Drive** — sistema externo desenvolvido pelo usuário que abstrai o SFTP do Mercado Livre e expõe os dados como REST autenticado por API key. A integração preserva 100% do domínio existente (`CompanyGrant`, página `/grants`, permissão `core.grants`, polling de status, dialogs de edit/regrant) e substitui apenas o pipeline de coleta + adiciona coluna `segmento` para uso comercial.

Purpose:
- **Acertividade**: o SFTP atual falha quando o IP da máquina não está na whitelist do Mercado Livre (banner `error_ip` já existe na UI), expira XLSX, depende de PhpSpreadsheet. A API HTTP é controlada pelo próprio ECF, com retry/timeout previsíveis e payload tipado — divergência silenciosa cai a zero.
- **Praticidade**: zero passos a mais para o admin (mesmo botão "Sincronizar agora", mesmo polling, mesma página). A diferença é só onde o dado vem; a UI ganha 1 coluna útil (`segmento`) e 1 label de origem ("via ECF Drive").

Output:
- 1 PLAN.md (este arquivo)
- Backend: `EcfDriveService` (wrapper HTTP) + comando `grants:sync-ecf` + migration `segmento` + schedule + adapter no `GrantController`
- Frontend: `Grants/Index.jsx` com coluna `segmento` + label "via ECF Drive"
- 9+ testes Feature em `tests/Feature/Phase20/`
- `SyncGrantsFromSftp.php` permanece intacto (rollback safety por +1 fase)
- W4 checkpoint humano: configurar `ECF_API_KEY` em prod, deploy, dry-run, apply, smoke UI

### EcfDriveService (app/Services/EcfDriveService.php) — autoritativo

```php
namespace App\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Http;
use Illuminate\Http\Client\PendingRequest;

/**
 * Phase 20 — wrapper HTTP do sistema externo ECF Drive
 * (https://files.ecfconsultoria.com.br/api/v1).
 * Substitui a coleta SFTP do Mercado Livre em /grants.
 */
class EcfDriveService
{
    private string $base;
    private string $key;

    public function __construct(?string $base = null, ?string $key = null)
    {
        $this->base = rtrim($base ?? (string) config('services.ecf.base'), '/');
        $this->key  = $key ?? (string) config('services.ecf.key', '');
    }

    /**
     * Lista grants paginados. Filtros aceitos:
     * - expirando_em_dias: int (?expirando_em_dias=N)
     * - expirado: bool|string
     * - from: 'YYYY-MM-DD'
     * - to: 'YYYY-MM-DD'
     * - search: string
     * - page: int (default 1)
     * - limit: int (default 100, max API-dependente)
     *
     * Retorna array decodificado: ['data' => Grant[], 'total' => int, ...]
     *
     * @throws \RuntimeException quando HTTP != 2xx após retry.
     */
    public function listGrants(array $filtros = []): array;

    /**
     * Detalhe de 1 cliente/grant por custId. Lança RuntimeException em 404.
     */
    public function cliente(string $custId): array;

    /**
     * Health check (GET /auth/me). True quando 2xx, false em qualquer outro caso.
     * NÃO lança — captura Throwable e retorna false.
     */
    public function ping(): bool;

    /**
     * Helper de conveniência cacheado 5min — chama listGrants(['expirando_em_dias' => $dias]).
     * Cache key: "ecf_drive:expirando:{dias}".
     */
    public function grantsExpirandoEm(int $dias): array;

    /**
     * Cliente HTTP base com headers obrigatórios + retry + timeout.
     */
    private function http(): PendingRequest
    {
        return Http::withHeaders([
            'X-Api-Key' => $this->key,
            'Accept'    => 'application/json',
        ])
        ->retry(2, 500)
        ->timeout(15)
        ->baseUrl($this->base);
    }
}
```

### Mapeamento API → company_grants (autoritativo)

| Campo API           | Campo DB                              | Observação |
|---------------------|---------------------------------------|------------|
| `custId`            | `ml_cust_id` + lookup `company_id`    | Chave de match primária |
| `email`             | `ml_email`                            | nullable |
| `telefone`          | `ml_phone`                            | nullable |
| `segmento`          | `segmento` (NOVO)                     | nullable string |
| `grantInicio`       | `granted_at`                          | cast date — Carbon::parse |
| `grantFim`          | `expires_at`                          | cast date — Carbon::parse |
| `expirado`          | `status`                              | true → 'expired'; false → 'active' (se granted_at <= today) ou 'pending' (se granted_at futuro) |
| `cnpj`              | (apenas lookup fallback)              | NÃO persistir em company_grants — Company já tem |
| `razaoSocial`       | (ignorar)                             | Company.name é autoritativo |
| `diasParaExpirar`   | (derivado por accessor existente)     | NÃO persistir — derivado de expires_at |

### Match company_id (autoritativo)

1. `companies.adman_account_id == $grant['custId']` (string-compare exato)
2. fallback: `companies.cnpj` normalizado (somente dígitos via `preg_replace('/\D/', '', $cnpj)`) == `$grant['cnpj']` normalizado
3. nenhum match → registrar em `storage/logs/grants-orfaos.log` no formato:
   ```
   [YYYY-MM-DD HH:MM:SS] ÓRFÃO custId=... cnpj=... razaoSocial=... payload={json}
   ```
   e incrementar contador `$orfaos`. NÃO criar Company automaticamente nesta fase.

## Decisões importantes registradas

**D-01: SyncGrantsFromSftp permanece intacto no repo (rollback safety por +1 fase)**
- *Por quê:* Caso a API ECF Drive apresente problema em produção, basta reverter o schedule em `routes/console.php` para `grants:sync-sftp` que o pipeline antigo volta. Remoção definitiva (composer deps SFTP + comando + disk `ml_sftp`) fica para Phase 22 após pelo menos 2 semanas de operação estável da API.

**D-02: Status `pending` mapeado quando `grantInicio` é futuro**
- *Por quê:* O pipeline SFTP populava `status='pending'` para linhas sem `expires_at`. A API ECF Drive sempre retorna `expirado: true|false`, mas pode emitir grants com `grantInicio` no futuro. Para preservar a semântica de 3 estados na UI (Ativo / Pendente / Expirado) sem perder informação, mapeamos `grantInicio > hoje → pending`. Justificativa adicional: Pitfall 6 do CONTEXT.md ("Status pending desaparece") fica resolvido.

**D-03: Match company_id usa `companies.adman_account_id` (não `ml_store_id`)**
- *Por quê:* O `SyncGrantsFromSftp.php` linha 121 usa `where('ml_store_id', $custId)` (campo legacy). O CONTEXT.md D-3 diz "companies.adman_account_id == ecf.custId" — semanticamente o cust_id da ECF Drive **é** o `adman_account_id` (id da conta Adman/marketplace). Esta é a fonte autoritativa no projeto pós-Phase 18.5 (marketplace dinâmico). Caso `adman_account_id` esteja vazio para a empresa, ainda existe o fallback CNPJ.
- *Mitigação retrocompat:* se durante smoke W4 o user reportar empresas com `ml_store_id` populado mas `adman_account_id` vazio, criar quick task pós-Phase 20 para backfill (não bloqueia esta fase).

**D-04: Cache 5min em `grantsExpirandoEm()` é apenas conveniência — UI sempre lê tabela local**
- *Por quê:* `Grants/Index.jsx` continua consumindo `GrantController::index` (autoritativo do banco). O método `grantsExpirandoEm` existe no `EcfDriveService` para futuros consumers (dashboard, alertas) mas NÃO é chamado em runtime durante render da página. CONTEXT.md Pitfall 7 fica honrado.

**D-05: Webhook secret mapeado em `.env` mas vazio até Phase 21**
- *Por quê:* CONTEXT.md D-4 — facilita Phase 21 que adiciona o endpoint webhook real-time. Nesta fase apenas registramos a chave para que o operador saiba que existe quando configurar prod.

**D-06: Coluna `segmento` truncada com tooltip na UI (responsivo)**
- *Por quê:* CONTEXT.md Pitfall 5 — a tabela `/grants` tem 7 colunas hoje (`grid-cols-[1fr_7rem_8rem_8rem_7rem_7rem_5rem]`). Adicionar Segmento estoura largura em laptop. Mitigação: nova coluna ~6rem, truncate com `title={g.segmento}` (tooltip nativo HTML) — sem dependência nova de tooltip component.

## Riscos residuais (documentados — não bloqueiam o plan)

**R-01: API ECF Drive offline durante deploy** — Probabilidade baixa, mas existe. Mitigação:
- Wrapper já tem `retry(2, 500)` + `timeout(15)`.
- W4 inclui `php artisan tinker --execute='(new EcfDriveService)->ping()'` antes do deploy do schedule.
- Catch `\Throwable` no comando → writeStatus 'done success=false' com mensagem; UI mostra erro sem corromper tabela.

**R-02: Cust_id ambíguo entre empresas (2+ matches por CNPJ no fallback)** — Cenário: empresa A migrou de cust_id histórico, empresa B reusou o cust_id antigo. Mitigação:
- Log explícito no `grants-orfaos.log` quando fallback CNPJ encontra >1 empresa: `MULTIMATCH custId=... cnpj=... matches=[id1,id2,...]`.
- NÃO atualizar nenhuma empresa nesse caso — marcar como órfão para revisão manual.

**R-03: API key vazada no histórico de chat** — Usuário colou `ecf_c7b9...` no briefing inicial. Mitigação:
- W4 (task humana) inclui passo explícito: "Revogar a key colada no chat e gerar nova diretamente no painel ECF Drive; salvar APENAS no `.env` do VPS via SSH; NUNCA commitar".
- `.env.example` documenta a variável com valor vazio.

**R-04: Rate limit ECF Drive desconhecido** — CONTEXT.md Pitfall 8 diz "briefing não menciona". Mitigação:
- Schedule MVP roda 1×/dia (alinhado ao SFTP atual). Se em uso interativo (botão "Sincronizar agora") observarmos 429, abrir quick task pós-Phase 20 para throttle.
- Wrapper já tem `retry(2, 500)` que absorve 1 rebound de 429 transitório.

**R-05: Coluna `segmento` quebrar testes existentes de CompanyGrant** — Mitigação:
- Migration é additive (nullable + default null). `$fillable` recebe `segmento` adicional — testes que usam `CompanyGrant::create([...sem segmento])` continuam OK.
- W3-T3 cobre roundtrip explicitamente.

    Estrutura:
    ```php
    namespace App\Console\Commands;

    use App\Models\Company;
    use App\Models\CompanyGrant;
    use App\Services\EcfDriveService;
    use Carbon\Carbon;
    use Illuminate\Console\Command;
    use Illuminate\Support\Facades\DB;

    class SyncGrantsFromEcfDrive extends Command
    {
        protected $signature = 'grants:sync-ecf {--dry-run : Exibe o que seria importado sem salvar no banco}';
        protected $description = 'Sincroniza grants do ML via API HTTP do ECF Drive (substitui o pipeline SFTP anterior).';

        public function handle(EcfDriveService $service): int
        {
            ignore_user_abort(true);
            set_time_limit(300);

            $dryRun = (bool) $this->option('dry-run');
            if ($dryRun) $this->warn('[dry-run] Nenhuma alteração será salva.');

            // writeStatus de início (idêntico ao SFTP) — só fora de dry-run
            if (! $dryRun) $this->writeStatus(['status' => 'running', 'started_at' => time()]);

            try {
                $page  = 1;
                $limit = 100;
                $recebidos = $matched = $created = $updated = $orfaos = 0;

                while (true) {
                    $r = $service->listGrants(['page' => $page, 'limit' => $limit]);
                    $data = $r['data'] ?? [];
                    $count = count($data);
                    if ($count === 0) break;
                    $recebidos += $count;

                    foreach ($data as $grant) {
                        $custId = $grant['custId'] ?? null;
                        if (! $custId) { $orfaos++; continue; }

                        $company = $this->resolveCompany($grant);
                        if (! $company) {
                            $this->logOrfao($grant, 'ÓRFÃO');
                            $orfaos++;
                            continue;
                        }
                        $matched++;

                        $grantData = $this->mapToDb($grant);

                        if ($dryRun) {
                            $this->line("[dry-run] {$company->name} → " . json_encode($grantData, JSON_UNESCAPED_UNICODE));
                            continue;
                        }

                        $row = CompanyGrant::updateOrCreate(
                            ['company_id' => $company->id, 'ml_cust_id' => $custId],
                            $grantData,
                        );
                        $row->wasRecentlyCreated ? $created++ : $updated++;
                    }

                    if ($count < $limit) break; // pitfall CONTEXT.md #4 — para na última página parcial
                    $page++;
                }

                $this->table(
                    ['Recebidos', 'Matched', 'Criados', 'Atualizados', 'Órfãos'],
                    [[$recebidos, $matched, $created, $updated, $orfaos]],
                );

                if (! $dryRun) {
                    $this->writeStatus([
                        'status'  => 'done',
                        'success' => true,
                        'message' => "Sincronização concluída via ECF Drive: {$created} criados, {$updated} atualizados, {$orfaos} órfãos.",
                    ]);
                }
                $this->info('Sincronização concluída.');
                return self::SUCCESS;
            } catch (\Throwable $e) {
                $msg = $e->getMessage();
                if (! $dryRun) {
                    $this->writeStatus(['status' => 'done', 'success' => false, 'error' => $msg]);
                }
                $this->error("Erro durante sync ECF Drive: {$msg}");
                return self::FAILURE;
            }
        }

        private function resolveCompany(array $grant): ?Company
        {
            // 1º match por adman_account_id (cust_id)
            $custId = $grant['custId'] ?? null;
            if ($custId) {
                $c = Company::where('adman_account_id', $custId)->where('active', true)->first();
                if ($c) return $c;
            }

            // 2º fallback CNPJ (só dígitos)
            $cnpj = preg_replace('/\D/', '', $grant['cnpj'] ?? '') ?: null;
            if (! $cnpj) return null;

            $driver = DB::connection()->getDriverName();
            if ($driver === 'sqlite') {
                $matches = Company::where('active', true)->get()
                    ->filter(fn($c) => preg_replace('/\D/', '', (string) ($c->cnpj ?? '')) === $cnpj);
            } else {
                // MySQL / MariaDB suportam REGEXP_REPLACE (MySQL 8+ / MariaDB 10.0+)
                $matches = Company::where('active', true)
                    ->whereRaw("REGEXP_REPLACE(COALESCE(cnpj, ''), '[^0-9]', '') = ?", [$cnpj])
                    ->get();
            }

            if ($matches->count() === 1) return $matches->first();
            if ($matches->count() > 1) {
                $this->logOrfao($grant, 'MULTIMATCH ids=[' . $matches->pluck('id')->implode(',') . ']');
                return null;
            }
            return null;
        }

        private function mapToDb(array $grant): array
        {
            $expirado = (bool) ($grant['expirado'] ?? false);
            $grantInicio = ! empty($grant['grantInicio']) ? Carbon::parse($grant['grantInicio']) : null;
            $grantFim    = ! empty($grant['grantFim'])    ? Carbon::parse($grant['grantFim'])    : null;

            if ($expirado) {
                $status = 'expired';
            } elseif ($grantInicio && $grantInicio->isFuture()) {
                $status = 'pending';
            } else {
                $status = 'active';
            }

            return [
                'ml_cust_id' => $grant['custId'],
                'ml_email'   => $grant['email']    ?: null,
                'ml_phone'   => $grant['telefone'] ?: null,
                'segmento'   => $grant['segmento'] ?: null,
                'granted_at' => $grantInicio?->toDateString(),
                'expires_at' => $grantFim?->toDateString(),
                'status'     => $status,
            ];
        }

        private function logOrfao(array $grant, string $tipo): void
        {
            $line = sprintf(
                "[%s] %s custId=%s cnpj=%s razaoSocial=%s payload=%s\n",
                now()->format('Y-m-d H:i:s'),
                $tipo,
                $grant['custId']      ?? '-',
                $grant['cnpj']        ?? '-',
                $grant['razaoSocial'] ?? '-',
                json_encode($grant, JSON_UNESCAPED_UNICODE),
            );
            @file_put_contents(storage_path('logs/grants-orfaos.log'), $line, FILE_APPEND);
        }

        private function writeStatus(array $data): void
        {
            @file_put_contents(storage_path('app/grants_sync_status.json'), json_encode($data));
        }
    }
    ```
