Devolver ao Comercial a visibilidade de "para onde foi essa empresa depois do fechamento":
a listagem passa a mostrar a situação do contrato **e há quanto tempo** ela está assim
(D-08), sem link e sem tela nova.

avisar. O badge com tempo é o que faz a pessoa perceber sozinha e cobrar.

Output: prop `contrato_badge` montada em lote no `ComercialController::listagem()`, coluna
"Contrato" na tabela e o teste que prova conteúdo + ausência de N+1.
</objective>

       nunca esvazia.

    com eager load (`Company::with(['contratosServico' => fn($q) => $q->where('ativo', true)->with('servico')])`)
    — não abrir query nova nem usar `whereHas` por linha.

    NÃO passar o model `ContratoAssinatura` inteiro para a prop: array achatado com as duas chaves
    nomeadas acima. Nenhum dado de signatário (nome, e-mail, CPF) atravessa para o browser.
