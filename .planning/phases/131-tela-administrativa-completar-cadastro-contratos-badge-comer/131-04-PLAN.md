## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| formulário do browser → `companies` / `contratos_servico` | escrita em cadastro que alimenta documento jurídico |
| botão do browser → Clicksign | ação que dispara chamadas HTTP externas e consome janela de rate limit |
| backend → browser | detalhe com dados de contrato e de pessoas que assinam |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-131-04-01 | Tampering (IDOR) | `contratos_servico[].id` no PATCH | mitigate | `exists:contratos_servico,id` + checagem de que cada `ContratoServico` pertence a `$company`, senão `abort(422)` — molde literal do `ContratoLiberacaoManualController::store()` (T-130-04-03) |
| T-131-04-02 | Tampering | mass assignment em `Company`/`ContratoServico` | mitigate | Gravar só as chaves validadas; `$fillable` explícito já existente nos dois models; nunca `$guarded = []` |
