|----------|-------------|
| `Configuracao` (banco) → prop Inertia → navegador | O estado do interruptor passa a ser visível para todo usuário com `permission:admin.contratos`. É informação operacional interna, não segredo — mas é a primeira vez que o estado da chave sai do servidor. |
| Backend → React | Toda decisão de exibição é calculada no servidor; o componente só renderiza. Lógica de decisão migrada para o client viraria controle que o usuário pode contornar. |
