# Plan 32-02: Página admin /nps/configuracao com preview live

Wave 2 — depende W1. Roda em paralelo com Plan 32-03 (touchs em arquivos distintos).

## Escopo

1. **NpsController** ganha 3 métodos:
   - `configuracao()` GET → retorna `Inertia::render('Nps/Configuracao', ['textos' => $textosAtuais, 'defaults' => $defaults, 'placeholders_doc' => $listaPlaceholders])`
   - `atualizarConfiguracao(Request)` PUT → valida 12 campos string max ~5000, persiste via `Configuracao::set('nps_textos', json_encode(...))`, `back()->with('success', 'Textos salvos.')`
   - `previewEmail(Request)` POST → renderiza `view('emails.nps.mensal', $varsExemplo)` com OS TEXTOS DO REQUEST (não os persistidos — permite preview sem salvar) → retorna `response()->json(['html' => $html])`

2. **routes/web.php** — 3 rotas dentro do grupo `middleware('auth', 'role:admin')`:
   - `Route::get('/nps/configuracao', [NpsController::class, 'configuracao'])->name('nps.configuracao.index');`
   - `Route::put('/nps/configuracao', [NpsController::class, 'atualizarConfiguracao'])->name('nps.configuracao.update');`
   - `Route::post('/nps/configuracao/preview', [NpsController::class, 'previewEmail'])->name('nps.configuracao.preview');`

3. **Nps/Configuracao.jsx** — form completo. Layout sugerido: 2 colunas (form à esquerda, preview iframe à direita) em desktop; stack em mobile. Use `Tabs` shadcn pra separar "Email" (assunto, saudação, corpo, CTA, assinatura) de "Perguntas" (5 textos da Respond) se preferir.

4. **AppLayout.jsx** — adiciona item no sidebar (sob NPS) só pra admin. Pode ser sub-link ou ícone settings.

```
nome_estrategista = 'Nathália'

```

## Verificação

- `php artisan route:list | grep nps.configuracao` mostra as 3 rotas
- Acesso a `/nps/configuracao` como admin renderiza a página
- Acesso como consultor/mentor → 403
- Salvar via PUT atualiza a chave `nps_textos` em `configuracoes`
- Preview POST retorna HTML que contém o logo (linear-gradient) + os textos enviados
- `npm run build` sem erros
