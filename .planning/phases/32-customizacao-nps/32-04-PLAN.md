# Plan 32-04: Página /nps/emails-enviados

Wave 3. Depende Plan 32-01 (precisa da tabela `nps_email_envios`). Independente de W2.

## Escopo

1. **NpsController::emailsEnviados(Request)** — query base:
   ```php
   $mes = $request->input('mes') ?: now()->format('Y-m');
   $inicio = Carbon::createFromFormat('Y-m', $mes)->startOfMonth();
   $fim    = $inicio->copy()->endOfMonth();

   $query = NpsEmailEnvio::with(['company:id,name', 'survey:id,token,status'])
       ->whereBetween('created_at', [$inicio, $fim])
       ->orderByDesc('created_at');

   if ($q = $request->input('q')) {
       $query->where(fn($w) => $w
           ->whereHas('company', fn($c) => $c->where('name', 'like', "%{$q}%"))
           ->orWhere('destinatario', 'like', "%{$q}%"));
   }

   $envios = $query->paginate(25)->appends($request->only(['mes', 'q']));
   ```

2. **routes/web.php** — `Route::get('/nps/emails-enviados', [NpsController::class, 'emailsEnviados'])->name('nps.emails-enviados.index')->middleware('role:admin');`

3. **EmailsEnviados.jsx** — lista paginada. Layout consistente com `Nps/Index.jsx`.

4. **AppLayout.jsx** — adiciona sub-item no sidebar NPS (admin only).

## Verificação

- Acesso `/nps/emails-enviados` como admin renderiza lista
- Filtro mês muda a URL e recarrega lista
- Busca por nome de empresa filtra (debounce 300ms)
- Total de envios do mês conta correto vs `DB::table('nps_email_envios')->whereBetween('created_at', ...)`
- Paginação funciona (criar 30+ envios fake via Tinker se necessário)
- Status=falha mostra erro_msg no tooltip/expand
- `npm run build` sem erros
