1. **Migration 1** — criar tabela `nps_email_envios`
2. **Migration 2** — popular `configuracoes` com chave `nps_textos` (JSON com defaults — exato shape do CONTEXT D-03)
3. **Model NpsEmailEnvio**
4. **Helper NpsTextRenderer** — métodos `render(string $template, array $vars)` e `renderHtml($template, $vars)` (com escape via `e()`)
5. **Partial Blade `logo-ecf.blade.php`** — HTML/CSS inline conforme spec D-01

8. **Comando NpsDispararMensal** — busca textos via `Configuracao::get('nps_textos')`, renderiza, dispara, grava `NpsEmailEnvio`
