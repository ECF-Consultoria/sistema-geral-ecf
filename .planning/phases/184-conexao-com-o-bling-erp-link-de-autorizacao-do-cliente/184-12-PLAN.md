os botões de cada um, o link para copiar e a prévia da importação.

vê.

teste JS de render.

    `{ bling, carregando, agindo, erro, gerarLink, desconectar, iniciarLeitura, importar, atualizarEstoque, previa, fecharPrevia }`.

    - `bling` começa como `inicial` (o que o Inertia já mandou em `conexoes.bling`) — a tela pinta
      **na primeira renderização**, sem esperar requisição;
    - `gerarLink()` → `POST route('mlb.anuncios.publicador.bling.link', { conta })`, e grava o
      `bling` novo devolvido (ou refaz o `estado`);
    - `desconectar()` → `DELETE route('mlb.anuncios.publicador.bling.desconectar', { conta })`,
      **com confirmação do usuário antes** (um `window.confirm` com texto em pt-BR, ou o diálogo do
      projeto se houver — conferir `Components/ui/dialog.jsx`): desconectar é destrutivo;
    - `iniciarLeitura()` → `POST .../bling/leitura`, guarda a `rodada` e começa um **polling** de
      `GET .../bling/leitura/{rodada}` a cada 3 s, que **para** quando `progresso.concluida` é
      verdadeiro, quando dá erro, ou depois de um teto de tentativas
      (`const MAX_TENTATIVAS = 200`, ~10 min — 500 produtos levam ~8,5 min). Polling sem teto é
      aba aberta batendo no servidor para sempre;
    - `importar()` → `POST .../bling/importar` com a `rodada`, e guarda o resultado (totais +
      `nao_entraram`);
    - `atualizarEstoque()` → `POST .../bling/estoque`;
    - `agindo` é o nome da ação em curso (string ou `null`), para a tela desabilitar **só** o botão
      clicado;
    - todo `catch` grava em `erro` a `message` que o servidor mandou (as rotas devolvem 422 com
      `message` em pt-BR), **nunca** um `JSON.stringify` do erro cru;
    - limpar o `setInterval`/`setTimeout` no `useEffect` de desmontagem — aba fechada no meio do
      polling não pode deixar timer vivo.

    Criar `tests/js/publicador-bling-configuracoes.test.js` e, nele, os casos **por fonte** do hook
    (padrão `lerSemComentarios`):

    2. existe um teto de tentativas de polling (a cadeia `MAX_TENTATIVAS` aparece) e ele é usado numa

    3. há limpeza de timer (`clearInterval` ou `clearTimeout`) — asserção NEGATIVA sobre vazamento;
