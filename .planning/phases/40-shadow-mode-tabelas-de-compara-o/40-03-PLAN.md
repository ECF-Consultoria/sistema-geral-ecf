    ```php
    public function compareRuns(int $admanRunId, int $mlRunId): array
    {
        $admanRun = \App\Models\SugadorProviderRun::with('items')->findOrFail($admanRunId);
        $mlRun = \App\Models\SugadorProviderRun::with('items')->findOrFail($mlRunId);
        return $this->compareCollections($admanRun->items, $mlRun->items);
    }

    public function compareWindow(int $companyId, \Carbon\Carbon $from, \Carbon\Carbon $to): array
    {
        $admanItems = \App\Models\SugadorProviderItem::whereHas('run', function($q) use ($companyId, $from, $to) {
            $q->where('company_id', $companyId)->where('provider', 'adman')
              ->whereBetween('reference_date', [$from->toDateString(), $to->toDateString()]);
        })->get();
        $mlItems = \App\Models\SugadorProviderItem::whereHas('run', function($q) use ($companyId, $from, $to) {
            $q->where('company_id', $companyId)->where('provider', 'ml')
              ->whereBetween('reference_date', [$from->toDateString(), $to->toDateString()]);
        })->get();
        return $this->compareCollections($admanItems, $mlItems);
    }
    ```

    Método privado `compareCollections(Collection $admanItems, Collection $mlItems): array`:
    1. Indexar ambos por chave canônica: `keyFor($item)` retorna `"{$item->tipo}|{$item->campaign_id}|{$item->adgroup_id}"` se adgroup_id não vazio, senão `"{$item->tipo}|{$item->campaign_id}|mlb:{$item->mlb_id}"` (fallback Plan 40-03 §match key)
    2. Para cada chave Adman: se chave existe em ML → comparar (matched/metrics_diff/motivo_diff/quarentena_diff). Se não existe → apenas_adman.
    3. Para cada chave ML não vista: apenas_ml.
    4. Comparação por chave (`compareItem($admanItem, $mlItem): string`):
       - Se um marca quarentena no motivo (`in_array(self::MARKER_QUARENTENA, $admanItem->motivos)` !== `in_array(self::MARKER_QUARENTENA, $mlItem->motivos)`) → return 'quarentena_diff'
       - Comparar métricas via `metricsMatch($adman->metrics_json, $ml->metrics_json)`: se false → 'metrics_diff'
       - Comparar motivos ordenados (sort + compact) — se diff → 'motivo_diff'
       - Senão → 'matched'
    5. Calcular paridade: `$total = matched + metrics_diff + motivo_diff + apenas_adman + apenas_ml + quarentena_diff`; `$paridade = $total > 0 ? round(($matched / $total) * 100, 2) : 100.0`
    6. Retornar array com 7 chaves: matched, metrics_diff, motivo_diff, apenas_adman, apenas_ml, quarentena_diff, paridade_motivos_pct (float).

    Helpers privados:
    - `metricsMatch(array $a, array $b): bool` — para cada campo dinheiro: `abs($a-$b) <= TOLERANCIA_DINHEIRO_ABS || abs($a-$b)/max(abs($a),abs($b),1) <= TOLERANCIA_DINHEIRO_PCT`. Para percentual: `abs($a-$b) <= TOLERANCIA_PERCENTUAL`. Para inteiro: `$a === $b`. null/null: match; null/value ou value/null: false (any campo basta pra false).
    - `keyFor(SugadorProviderItem $item): string`
