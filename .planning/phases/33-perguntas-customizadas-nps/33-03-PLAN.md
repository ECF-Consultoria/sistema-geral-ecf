# Plan 33-03: Respond.jsx renderiza perguntas customizadas

Wave 2 — depende W1. Paralelo com Plan 33-02 e 33-04.

## Escopo

1. **Adicionar ao useForm() data**:
   ```js
   respostas_extras: Object.fromEntries(
     (perguntas_extras || []).map(p => [p.id, p.tipo === 'escala_1_5' ? null : ''])
   ),
   ```

2. **Componentes de render por tipo** — pode criar inline ou helper functions:
   ```jsx
   function PerguntaExtra({ pergunta, valor, onChange, error }) {
     switch (pergunta.tipo) {
       case 'escala_1_5':
         return <RatingPicker value={valor} onChange={onChange} />
       case 'texto':
         return <textarea value={valor} onChange={e => onChange(e.target.value)} maxLength={2000} className="..." />
       case 'sim_nao':
         return (
           <div className="flex gap-3">
             <button type="button" onClick={() => onChange('sim')} className={cn('flex-1 ...', valor === 'sim' && 'bg-emerald-500/30 border-emerald-500')}>SIM</button>
             <button type="button" onClick={() => onChange('nao')} className={cn('flex-1 ...', valor === 'nao' && 'bg-rose-500/30 border-rose-500')}>NÃO</button>
           </div>
         );
       case 'multipla':
         return (
           <div className="space-y-2">
             {(pergunta.opcoes || []).map(opt => (
               <label key={opt} className="flex items-center gap-2 cursor-pointer rounded-lg border border-white/[0.08] px-3 py-2 hover:bg-white/[0.03]">
                 <input type="radio" name={`p${pergunta.id}`} value={opt} checked={valor === opt} onChange={() => onChange(opt)} className="accent-ecf-yellow" />
                 <span className="text-white text-sm">{opt}</span>
               </label>
             ))}
           </div>
         );
     }
   }
   ```

3. **Inserir o loop de perguntas extras no JSX** entre o bloco de "Pergunta empresa" (3ª fixa) e o bloco "Comentário":
   ```jsx
   {(perguntas_extras || []).map(p => (
     <div key={p.id} className="space-y-3">
       <label className="block text-xs text-white/70 font-medium uppercase tracking-wide">
         {p.texto} {p.obrigatorio && <span className="text-ecf-yellow">*</span>}
       </label>
       <PerguntaExtra pergunta={p} valor={data.respostas_extras[p.id]} onChange={v => setData('respostas_extras', { ...data.respostas_extras, [p.id]: v })} error={errors[`respostas_extras.${p.id}`]} />
       {errors[`respostas_extras.${p.id}`] && <p className="text-red-400 text-xs">{errors[`respostas_extras.${p.id}`]}</p>}
     </div>
   ))}
   ```

4. **isValid local** — atualizar para incluir validação das obrigatórias:
   ```js
   const todasObrigatoriasOk = (perguntas_extras || []).filter(p => p.obrigatorio).every(p => {
     const v = data.respostas_extras[p.id];
     return v !== null && v !== '' && v !== undefined;
   });
   ```

5. **Sem deploy nesta plan**; build local + smoke visual.
