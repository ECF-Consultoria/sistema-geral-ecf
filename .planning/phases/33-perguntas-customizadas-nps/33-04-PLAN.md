# Plan 33-04: Modal "Abrir" na lista /nps com todas respostas

Wave 2 — depende W1. Paralelo com 33-02 e 33-03.

## Escopo

1. **NpsController::index** — adicionar eager load:
   ```php
   ->with(['response.respostasCustomizadas']) // + survey base ja eager loaded
   ```
   Passar para o payload Inertia cada survey com:
   ```php
   'response' => $survey->response ? [
       'score_estrategista' => $survey->response->score_estrategista,
       'score_analista' => $survey->response->score_analista,
       'score_empresa' => $survey->response->score_empresa,
       'comment' => $survey->response->comment,
       'respondent_name' => $survey->response->respondent_name,
       'respondida_em' => $survey->response->created_at?->toIso8601String(),
       'respostas_customizadas' => $survey->response->respostasCustomizadas->map(fn($r) => [
           'pergunta_texto' => $r->pergunta_texto_snapshot,
           'tipo' => $r->tipo_snapshot,
           'valor' => $r->valor,
       ])->values(),
   ] : null,
   ```

2. **Nps/Index.jsx**:
   - Importar `Dialog, DialogContent, DialogHeader, DialogTitle, DialogFooter` de `@/Components/ui/dialog`
   - Importar `Eye` de lucide-react
   - State `modalSurvey` (null | survey object)
   - Botão na coluna Link ou nova coluna "Detalhes":
     ```jsx
     {survey.status === 'completed' && (
       <Button size="sm" variant="ghost" onClick={() => setModalSurvey(survey)}>
         <Eye className="h-4 w-4" />
       </Button>
     )}
     ```
   - Modal:
     ```jsx
     <Dialog open={!!modalSurvey} onOpenChange={open => !open && setModalSurvey(null)}>
       <DialogContent className="max-w-2xl bg-ecf-card border-white/[0.08]">
         <DialogHeader>
           <DialogTitle>{modalSurvey?.company?.name} — Resposta NPS</DialogTitle>
         </DialogHeader>
         {/* 3 blocos: header info, notas, comentario, extras */}
       </DialogContent>
     </Dialog>
     ```
   - Bloco Notas: mostra os 3 scores com cor (1-2 vermelho, 3 amarelo, 4-5 verde) e "X/5"
   - Bloco Comentário: texto em card cinza claro
   - Bloco Respostas extras: lista cada entrada com label da pergunta + valor formatado por tipo

3. **Format helpers**:
   ```js
   function formatExtraValor(tipo, valor) {
     if (tipo === 'sim_nao') return valor === 'sim' ? '✓ Sim' : '✗ Não';
     if (tipo === 'escala_1_5') return `${valor}/5`;
     return valor; // texto e multipla mostram raw
   }
   ```

## Verificação

- Acesso `/nps` → linhas respondidas têm botão olho; pending não tem
- Click abre modal com infos completas
- Modal fecha ao clicar fora ou X
- Survey sem respostas custom não mostra o bloco "Respostas extras"
- Survey com respostas custom mostra todas com formatação correta
- `npm run build` verde
