# Plan 33-01: Fundação — schema + models + endpoints + submit dinâmico

Wave 1. Bloqueia W2 (UI admin), W3 (UI cliente), W4 (modal lista).

## Escopo

1. **Migration `2026_06_12_100001_create_nps_perguntas_customizadas_table.php`**:
   - Colunas conforme D-01
   - tipo enum literal `['escala_1_5', 'texto', 'sim_nao', 'multipla']`
   - opcoes JSON nullable
   - ordem int default 0
   - ativa boolean default true
   - obrigatorio boolean default false

2. **Migration `2026_06_12_100002_create_nps_respostas_customizadas_table.php`**:
   - `response_id` FK `nps_responses` onDelete cascade
   - `pergunta_id` FK `nps_perguntas_customizadas` nullable onDelete set null
   - `pergunta_texto_snapshot` varchar 500
   - `tipo_snapshot` varchar 20
   - `valor` text
   - index em `response_id`

3. **Models**:
   - `NpsPerguntaCustomizada` — `$fillable = ['texto', 'tipo', 'opcoes', 'obrigatorio', 'ordem', 'ativa']`, `$casts = ['opcoes' => 'array', 'obrigatorio' => 'bool', 'ativa' => 'bool', 'ordem' => 'int']`. Const com lista de tipos válidos `TIPOS = ['escala_1_5', 'texto', 'sim_nao', 'multipla']`.
   - `NpsRespostaCustomizada` — `$fillable = ['response_id', 'pergunta_id', 'pergunta_texto_snapshot', 'tipo_snapshot', 'valor']`. Relacionamento `pergunta()` belongsTo.
   - `NpsResponse` (existente) ganha `respostasCustomizadas()` hasMany.

4. **NpsController** — adicionar 4 métodos CRUD para perguntas:
   ```php
   public function criarPerguntaExtra(Request $r) { /* validate, ordem = max+1, return back()->with('success') */ }
   public function atualizarPerguntaExtra(Request $r, NpsPerguntaCustomizada $p) { /* validate, update */ }
   public function excluirPerguntaExtra(Request $r, NpsPerguntaCustomizada $p) {
       $temRespostas = $p->respostas()->exists() ?? NpsRespostaCustomizada::where('pergunta_id', $p->id)->exists();
       if ($temRespostas && !$r->boolean('force')) {
           $p->update(['ativa' => false]);
           return back()->with('success', 'Pergunta desativada (tem respostas associadas).');
       }
       $p->delete(); // FK em respostas vira null via onDelete set null
       return back()->with('success', 'Pergunta removida.');
   }
   public function moverPerguntaExtra(Request $r, NpsPerguntaCustomizada $p) {
       $direcao = $r->validate(['direcao' => 'required|in:up,down'])['direcao'];
       // Busca vizinho com (ordem,id) menor (up) ou maior (down), troca ordem entre eles
       // ... implementação trivial
   }
   ```
   Validação criar/atualizar:
   ```php
   $r->validate([
       'texto' => 'required|string|max:500',
       'tipo' => ['required', Rule::in(NpsPerguntaCustomizada::TIPOS)],
       'opcoes' => ['nullable', 'array', 'required_if:tipo,multipla'],
       'opcoes.*' => 'string|max:255',
       'obrigatorio' => 'boolean',
       'ativa' => 'boolean',
   ]);
   ```

5. **NpsController::respond** — adicionar ao payload:
   ```php
   'perguntas_extras' => NpsPerguntaCustomizada::where('ativa', true)
       ->orderBy('ordem')->orderBy('id')
       ->get(['id', 'texto', 'tipo', 'opcoes', 'obrigatorio']),
   ```

6. **NpsController::submitResponse** — receber `respostas_extras` (formato sugerido: array de objetos `{pergunta_id, valor}` ou hash `{pergunta_id: valor}`). Validar dinamicamente:
   - Carrega perguntas ativas atuais
   - Para cada pergunta obrigatoria, checa que veio resposta válida
   - Para cada resposta recebida, valida conforme tipo (matriz D-02)
   - Dentro do `DB::transaction` da response principal, persiste `NpsRespostaCustomizada` com snapshot de texto/tipo

7. **NpsController::index** — eager load `responses.respostasCustomizadas` com `pergunta` (para o nome atual ou fallback no snapshot). Adicionar `perguntas_extras` ao payload da página config (ver Plan 33-02).

8. **Rotas em `routes/web.php`** — sob middleware role:admin já existente do Plan 32-02:
   ```php
   Route::post('/nps/configuracao/perguntas', [NpsController::class, 'criarPerguntaExtra'])->name('nps.configuracao.perguntas.criar');
   Route::put('/nps/configuracao/perguntas/{pergunta}', [NpsController::class, 'atualizarPerguntaExtra'])->name('nps.configuracao.perguntas.atualizar');
   Route::delete('/nps/configuracao/perguntas/{pergunta}', [NpsController::class, 'excluirPerguntaExtra'])->name('nps.configuracao.perguntas.excluir');
   Route::post('/nps/configuracao/perguntas/{pergunta}/mover', [NpsController::class, 'moverPerguntaExtra'])->name('nps.configuracao.perguntas.mover');
   ```
