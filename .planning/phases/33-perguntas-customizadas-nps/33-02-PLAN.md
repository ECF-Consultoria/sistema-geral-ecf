# Plan 33-02: Aba "Perguntas extras" no /nps/configuracao

Wave 2 — depende W1. Roda em paralelo com Plan 33-03 (touchs em arquivos distintos) e Plan 33-04 (idem).

## Escopo

1. **NpsController::configuracao()** — passa a incluir no payload:
   ```php
   'perguntas_extras' => NpsPerguntaCustomizada::orderBy('ordem')->orderBy('id')->get(),
   ```

2. **Nps/Configuracao.jsx**:
   - Importar `Switch` shadcn se ainda não estiver
   - Adicionar 3ª TabsTrigger "Perguntas extras" e respectivo TabsContent
   - State local:
     - `formNovaPergunta` (texto, tipo, opcoes[], obrigatorio, ativa) com defaults vazios + tipo='escala_1_5'
     - `editandoId` (null ou id da pergunta sendo editada)
   - Renderização da lista:
     - Cada pergunta como card horizontal: [↑] [↓] | texto + badges (tipo, obrig, ativa) | [Editar] [Excluir]
     - Para tipo=multipla, listar opções como mini-chips abaixo do texto
   - Form de criar/editar:
     - Inline acima da lista quando `editandoId === null` (criação) ou em-linha no card quando editando
     - Campo opcoes só aparece quando tipo === 'multipla' — input com adicionar/remover tags
     - Botões Salvar / Cancelar
   - Acoes:
     - Switch ativa: `router.put(route('nps.configuracao.perguntas.atualizar', p.id), { ativa: novoValor }, { preserveScroll: true })` (Inertia preserva o resto do form)
     - ↑↓: `router.post(route('nps.configuracao.perguntas.mover', p.id), { direcao: 'up'|'down' }, { preserveScroll: true })`
     - Excluir: `if (confirm('Excluir essa pergunta?')) router.delete(route('nps.configuracao.perguntas.excluir', p.id))`
     - Editar: preenche `formEditando`, oculta form de criação
   - Layout 2 colunas mantido (form de textos email/perguntas fixas à esquerda, preview à direita) — a 3ª aba ocupa o espaço inteiro (full-width) substituindo o split de Email/Perguntas, ou mantém só o form sem preview (escolha do executor — preview de email não faz sentido pra perguntas extras)

3. **Tipos válidos no Select** (constante JSX):
   ```js
   const TIPOS_PERGUNTA = [
     { value: 'escala_1_5', label: 'Escala 1 a 5' },
     { value: 'texto', label: 'Texto livre' },
     { value: 'sim_nao', label: 'Sim / Não' },
     { value: 'multipla', label: 'Múltipla escolha' },
   ];
   ```

## Verificação

- Acesso `/nps/configuracao` como admin → 3ª aba visível
- Criar pergunta sim_nao via UI: aparece na lista após submit
- Editar texto: persiste
- Mover ↑↓: ordem atualiza
- Toggle ativa via switch: persiste sem fechar form
- Criar pergunta multipla sem opções → backend retorna erro 422; UI mostra flash error
- `npm run build` verde
