### ⚠️ Por que PORTAL é obrigatório aqui (restrição concreta, não preferência)

O `<header>` tem `backdrop-blur-[14px] backdrop-saturate-[1.4]`. **`backdrop-filter` cria um
containing block para descendentes `position: fixed`** — um overlay `fixed inset-0` dentro do header
seria posicionado em relação ao HEADER, não à janela, e o modal nasceria recortado dentro de uma
faixa de 109px. Somando a isso, o header vive dentro do `<main>` com `overflow-y-auto` e **D2 proíbe
tocar no `AppLayout`**. Portanto: `@radix-ui/react-dialog` com `Dialog.Portal`, como o 177-06 fez
com os dois popovers. Escreva esse motivo no topo do arquivo.

### A casca — medidas do protótipo (**:133-134**)

Fundo (**:133**): `position:fixed; inset:0; z-index:80; background:rgba(0,0,0,0.65)`.
Caixa (**:134**): `width:620px; background:#111111; border:1px solid #2E2E2E; border-radius:16px;
box-shadow:0 30px 80px rgba(0,0,0,0.8); overflow:hidden`, alinhada ao **topo** com
`padding-top:110px` e **centralizada na horizontal**.

⚠️ **Exporte as duas listas de classe como constantes nomeadas:**

```js
export const CLASSES_FUNDO = 'fixed inset-0 z-[80] bg-black/[0.65]';
export const CLASSES_CAIXA = 'fixed left-1/2 top-[110px] z-[80] w-[620px] -translate-x-1/2 overflow-hidden rounded-pub-card border border-pub-line-strong bg-pub-surface font-pub text-pub-txt shadow-pub-modal';
```
**Por quê:** o renderizador de servidor do React **não** suporta portal — nada dentro de
`Dialog.Portal` aparece no HTML de `react-dom/server`. Sem as constantes, a geometria da casca só
poderia ser conferida por leitura de fonte, que é gate fraco. Com elas, o gate compara a **string
inteira** por igualdade e confere que o JSX as **usa** (`className={CLASSES_CAIXA}`), para a
constante não poder divergir do render. Meça cada classe no protótipo e ajuste as strings acima se
divergirem.

- `bg-black/[0.65]` é exatamente `rgba(0,0,0,0.65)`. Não há token `pub-*` para preto puro com alfa
  e **não invente um** — `black` é cor padrão do Tailwind e não é hex literal (TOK-15 ok). Declare
  na SUMMARY.
- ⚠️ **Divergência de MECANISMO declarada:** o protótipo centraliza com um contêiner flex
  (`display:flex; justify-content:center; align-items:flex-start; padding-top:110px`). Com o Radix,
  `Overlay` e `Content` são irmãos, então a caixa se posiciona com `fixed left-1/2 top-[110px]
  -translate-x-1/2`. **O resultado computado é idêntico** para uma caixa de largura fixa: 110px do
  topo, centrada. Escreva isso.
- ⚠️ **`font-pub` na caixa é obrigatório.** O portal sai da subárvore do `<header>` e vai para o
  `document.body`, que é `font-sans` (Inter). Sem `font-pub` na `Dialog.Content`, **o modal inteiro
  perde a Geist em silêncio** — é a mesma armadilha que os dois `Popover.Content` do 177-06 tiveram.

### Comportamento

- `<Dialog.Root open={aberto} onOpenChange={(valor) => { if (!valor) aoFechar(); }}>` — sem
  `Dialog.Trigger`: quem abre são os botões do header (dois chamadores, uma função).
- `Dialog.Overlay` com `CLASSES_FUNDO`; `Dialog.Content` com `CLASSES_CAIXA`.
- ⚠️ **NÃO desabilitar** `onEscapeKeyDown` nem `onPointerDownOutside`: Esc e clique fora são do
  Radix e são exatamente o que NOVA-09 exige. O gate terá asserção **negativa** provando que não
  foram desligados (molde: `ConexaoDoHeader`/`SeletorDeEmpresaDoHeader`).
- **Foco no input** (NOVA-09): `onOpenAutoFocus={(evento) => { evento.preventDefault();
  inputRef.current?.focus(); }}`. O protótipo usa `setTimeout(…, 30)` (**:204**) porque lá não há
  gerenciador de foco; aqui o Radix já foca no primeiro elemento focável e o `preventDefault` +
  `focus()` torna o alvo **determinístico** em vez de depender da ordem do DOM. Declare.
- **Título acessível:** o Radix avisa quando a `Dialog.Content` não tem `Dialog.Title`. O protótipo
  não tem título visível — use `<Dialog.Title className="sr-only">Nova publicação</Dialog.Title>`
  (`sr-only` é classe padrão do Tailwind, permitida pelos gates). **Nenhum título visível** é
  acrescentado à tela: a geometria do protótipo não tem um.
- **O corpo** é `<PainelNovaPublicacao … />` **importado** da wave 2. **Não reimplemente nada do
  corpo aqui.**
- **Estado local:** `consulta` (string) e os três do fetch (`dados`, `carregando`, `erro`).
  Ao fechar, **zere a consulta** — é o `mq: ''` do `open()` do protótipo (**:204**).
