# Plan 34-03: Admin UI + Comercial edit + Show — novos campos + máscaras

Wave 2. Depende W1. Paralelo com Plan 34-02 e Plan 34-04.

## Escopo

Aplicar os campos novos em 3 sites JSX restantes (NovaEmpresa.jsx é o Plan 34-02):

1. **`CompanyController::store + update`** — adicionar mesmos rules de validation do Plan 34-02:
   ```php
   'nicho'                => 'nullable|string|max:255',
   'dor'                  => 'nullable|string|max:5000',
   'vende_ml'             => 'nullable|boolean',
   'faturamento_mensal'   => 'nullable|numeric|min:0|max:99999999.99',
   'marketplaces_extras'  => 'nullable|array',
   'marketplaces_extras.*' => [Rule::in(['shopee','amazon','magalu','temu','tiktok'])],
   'email_colaborador'    => 'nullable|email|max:255',
   ```

2. **`ComercialController::update`** — idem.

3. **`Companies/Index.jsx`**:
   - Adicionar `empresa_nova` ao PENDENCIAS const (linha 80)
   - Modal: bloco "Informações do close" com 6 inputs + email_colaborador separado (label: "Email colaborador ECF" vs "Email do cliente (NPS)")
   - Mascaras IMaskInput em CNPJ e telefone do modal
   - Botão "Marcar como visto" na linha quando `c.pendencias.includes('empresa_nova') && isAdmin`:
     ```jsx
     <button onClick={() => router.post(route('companies.marcar-visto', c.id), {}, { preserveScroll: true })} title="Marcar empresa como vista">
       <Check className="h-4 w-4" />
     </button>
     ```

4. **`Companies/Show.jsx`** — nova seção "Informações do Close" (estética dos outros blocos):
   ```jsx
   <section className="rounded-2xl border border-white/[0.08] bg-ecf-card p-6 space-y-4">
     <h2 className="text-white font-semibold">Informações do Close</h2>
     <div className="grid grid-cols-2 gap-4">
       <Field label="Nicho">{company.nicho ?? '—'}</Field>
       <Field label="Faturamento mensal">{formatCurrency(company.faturamento_mensal)}</Field>
       <Field label="Já vende no Mercado Livre?">{vendeMlLabel(company.vende_ml)}</Field>
       <Field label="Marketplaces extras"><MpExtrasChips items={company.marketplaces_extras} /></Field>
       <Field label="Email cliente (NPS)">{company.email_cliente ?? '—'}</Field>
       <Field label="Email colaborador ECF">{company.email_colaborador ?? '—'}</Field>
     </div>
     {company.dor && (
       <div>
         <p className="text-xs text-white/40 uppercase tracking-wide">Dor / contexto</p>
         <p className="whitespace-pre-wrap text-white/80 mt-1">{company.dor}</p>
       </div>
     )}
   </section>
   ```

5. **`Comercial/Empresas.jsx`** — edit form ganha os mesmos campos + IMaskInput.
