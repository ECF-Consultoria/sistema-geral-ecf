# Plan 34-01: Schema + pendências + endpoint "marcar visto"

Wave 1. Bloqueia W2 (UI cadastro + edit) e W3 (webhook HubSpot).

## Escopo

Conforme `must_haves.truths`. Resumo:

1. **Migration `300001` — colunas em `companies`** (defensiva com `Schema::hasColumn`):
   - nicho, dor, vende_ml, faturamento_mensal, marketplaces_extras, email_colaborador, empresa_nova, empresa_nova_visto_em, empresa_nova_visto_por

2. **Migration `300002` — tabela `hubspot_eventos`** (schema D-02). NÃO popula nada (Plan 34-04 alimenta via webhook).

3. **`app/Models/Company.php`** — adicionar todos os fillable + casts conforme D-01 + D-09.

4. **`app/Models/HubspotEvento.php`** novo:
   ```php
   $fillable = ['signature_valid','portal_id','object_type','object_id','subscription_type','property_name','property_value','payload','status','erro_msg','company_id_criada','processado_em'];
   $casts = ['signature_valid' => 'bool', 'payload' => 'array', 'processado_em' => 'datetime'];
   public function companyCriada() { return $this->belongsTo(Company::class, 'company_id_criada'); }
   ```

5. **`CompanyController::index`** — 2 ajustes:
   - Linha 100 (BUG): `(! $c->email_cliente) ? 'sem_email_colaborador' : null` → `(! $c->email_colaborador) ? 'sem_email_colaborador' : null`
   - Adicionar pendência `empresa_nova`: `$c->empresa_nova ? 'empresa_nova' : null` no array_filter
   - Payload por empresa: incluir nicho, dor, vende_ml, faturamento_mensal, marketplaces_extras, email_colaborador, empresa_nova

6. **`CompanyController::marcarVisto(Request, Company $company)`** — método novo:
   ```php
   abort_unless($request->user()->isAdmin(), 403);
   $company->update([
       'empresa_nova' => false,
       'empresa_nova_visto_em' => now(),
       'empresa_nova_visto_por' => $request->user()->id,
   ]);
   return back()->with('success', "Empresa {$company->name} marcada como vista.");
   ```

7. **`routes/web.php`** — adicionar dentro do grupo middleware role:admin já existente:
   ```php
   Route::post('/companies/{company}/marcar-visto', [CompanyController::class, 'marcarVisto'])->name('companies.marcar-visto');
   ```
