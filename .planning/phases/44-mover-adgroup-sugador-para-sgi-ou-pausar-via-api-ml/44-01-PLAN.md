Etapa 3 (POST criar SGI teste — Variante A):
  URL: https://api.mercadolibre.com/marketplace/advertising/{site_id}/advertisers/{advertiser_id}/product_ads/campaigns?channel=marketplace
  Headers: Authorization Bearer, api-version: 2, Content-Type: application/json
  Body: {name: "SGI-SMOKE-TEST-{ts}", status: "paused", budget: 5, strategy: "profitability", acos_target: 15, channel: "marketplace"}
  Espera HTTP 200/201 com body contendo `id` (= newCampaignId).
  Se HTTP 404 → tentar Variante B: POST /advertising/product_ads_2/campaigns body {budget: 5, status: "paused", name: "SGI-SMOKE-TEST-{ts}"}.
  Se ambas falharem → registrar bloco completo no relatório e ABORTAR (próximas etapas não tentam).

Etapa 4 (PUT mover ad teste pra SGI criada):
  URL: https://api.mercadolibre.com/marketplace/advertising/{site_id}/product_ads/ads/{item_id}?channel=marketplace
  Headers: Authorization Bearer, api-version: 2, Content-Type: application/json
  Body: {campaign_id: newCampaignId}
  Espera HTTP 200/204. Se 403 → registrar como blocker "scope/permissão" e ABORTAR.

Etapa 5 (PUT reverter ad pra campaign_id original):
  URL idêntica à Etapa 4
  Body: {campaign_id: originalCampaignId}
  Espera HTTP 200/204.

Etapa 6 (relatório): imprime CLI tabela com {step, ok, status_code, url, latency_ms, error?} + grava fixture JSON.
