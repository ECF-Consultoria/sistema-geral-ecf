# Wave 2 — Rota + página placeholder EmDesenvolvimento

## Objective

Criar rota `/em-desenvolvimento` + componente React `EmDesenvolvimento.jsx` que serve como placeholder para os stubs de marketplaces em desenvolvimento (Shopee, Amazon). Ao clicar em `Shopee` ou `Amazon` na sidebar (Wave 1), o usuário cai nessa página com feedback claro do design system ECF.

Depende de Wave 1 para os items da sidebar estarem apontando pra `route('em-desenvolvimento')`; sem esta wave, Ziggy vai erro na página com "Route [em-desenvolvimento] not defined".

## Tasks

### Task 1 — Registrar rota `/em-desenvolvimento` em routes/web.php

<action>
Em [routes/web.php](../../../routes/web.php) adicionar uma rota GET dentro do grupo de rotas autenticadas (que usa middleware `auth`).

O padrão do arquivo é: as rotas públicas ficam no topo (linhas ~46-74), depois vem o middleware group `->middleware(['auth', 'verified'])` (ou apenas `auth`) que engloba todas as rotas do sistema. Localizar esse grupo e adicionar a nova rota como uma das primeiras (logo após dashboard/redirect, antes de rotas específicas por módulo).

Estrutura da rota:

```php
// ─── Multi-marketplace: rota placeholder para marketplaces em desenvolvimento
//     (Shopee, Amazon, Magazine Luiza, etc). Sidebar (AppLayout.jsx) aponta stubs
//     para cá com query param ?marketplace=<slug>.  Phase 56 v13.0.
Route::get('/em-desenvolvimento', function () {
    return Inertia::render('EmDesenvolvimento', [
        'marketplace' => request()->query('marketplace'),
    ]);
})->name('em-desenvolvimento');
```

Notas:
- Nome nominal `em-desenvolvimento` (hífen) — casa com o `routeName` usado no `NAV_TREE` da Wave 1.
- Sem `permission` no `NAV_TREE` correspondente → todos autenticados podem acessar (padrão do Manual do Sistema).
- Nenhum controller próprio — closure inline é suficiente (Inertia + prop marketplace opcional).
- Import de `Inertia`: geralmente já está no topo de `routes/web.php` (usado por outras rotas). Se não estiver: `use Inertia\Inertia;` no topo do arquivo.
</action>

### Task 2 — Criar componente `resources/js/Pages/EmDesenvolvimento.jsx`

<action>
Criar arquivo NOVO em `resources/js/Pages/EmDesenvolvimento.jsx` — página React renderizada pela rota da Task 1.

Estrutura mínima (React + Inertia + Tailwind com tokens `ecf-*` + `AppLayout` como wrapper para manter sidebar/header/toast):

```jsx
import { Link, Head } from '@inertiajs/react';
import { Construction, ArrowLeft } from 'lucide-react';
import AppLayout from '@/Layouts/AppLayout';
import { cn } from '@/lib/utils';

// Labels amigáveis dos marketplaces conhecidos. Se o query param vier com
// slug não mapeado, cai no default genérico ("Marketplace").
const MARKETPLACE_LABEL = {
    shopee: 'Shopee',
    amazon: 'Amazon',
    magalu: 'Magazine Luiza',
};

export default function EmDesenvolvimento({ marketplace }) {
    const label = MARKETPLACE_LABEL[marketplace] ?? 'Marketplace';
    const title = `${label} em desenvolvimento`;

    return (
        <AppLayout title={title}>
            <Head title={title} />

            <div className="min-h-[60vh] flex items-center justify-center px-6">
                <div className={cn(
                    'w-full max-w-lg rounded-2xl border border-white/[0.08]',
                    'bg-ecf-card p-8 md:p-10 text-center shadow-lg'
                )}>
                    {/* Icone destacado */}
                    <div className={cn(
                        'mx-auto mb-6 flex items-center justify-center',
                        'w-16 h-16 rounded-full bg-ecf-yellow/[0.12]',
                        'border border-ecf-yellow/30'
                    )}>
                        <Construction size={32} className="text-ecf-yellow" />
                    </div>

                    <h1 className="text-white text-2xl font-display font-bold mb-3">
                        {title}
                    </h1>

                    <p className="text-white/70 text-[15px] leading-relaxed mb-2">
                        O módulo <strong className="text-white">{label}</strong> ainda não
                        está integrado ao ECF Admin.
                    </p>

                    <p className="text-white/50 text-sm leading-relaxed mb-8">
                        Estamos preparando a estrutura multi-marketplace do sistema. Fique
                        atento às próximas atualizações — este espaço será a porta de entrada
                        do seu operacional em {label}.
                    </p>

                    <Link
                        href={route('dashboard')}
                        className={cn(
                            'inline-flex items-center gap-2 rounded-lg px-4 py-2.5',
                            'bg-ecf-yellow text-[#252525] text-[13px] font-semibold',
                            'hover:bg-ecf-yellow/90 transition-colors'
                        )}
                    >
                        <ArrowLeft size={16} />
                        Voltar ao Dashboard
                    </Link>
                </div>
            </div>
        </AppLayout>
    );
}
```

Notas:
- `AppLayout` wraps a página → sidebar + header aparecem normalmente. Usuário não fica "isolado" no placeholder.
- Icone `Construction` do lucide-react (obra em desenvolvimento) — semanticamente casa com "em desenvolvimento".
- `bg-ecf-card` é token definido em `tailwind.config.js` (`#0f1116` conforme CLAUDE.md).
- `ecf-yellow` (`#ffe600`) é o CTA principal — padrão do design system para ação primária.
- Comentários em pt-BR conforme convenção.
- Sem lógica de admin/permissão — página pública para autenticados.
</action>
