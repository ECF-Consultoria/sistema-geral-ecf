# Plan 36-02: Atribuir Serviço migra pro Comercial + UX modal

Wave 1. Independente de 36-01 (arquivos distintos). Roda em paralelo.

## Escopo

1. **`ComercialController`** — adicionar método:
   ```php
   public function atribuirServico(Company $company)
   {
       abort_unless(
           auth()->user()->hasPermission('comercial.cadastrar_empresa') || auth()->user()->isAdmin(),
           403
       );

       $contratos = $company->contratosServico()
           ->with('servico')
           ->orderByDesc('data_contratacao')
           ->get()
           ->map(fn($ct) => [
               'id' => $ct->id,
               'servico_id' => $ct->servico_id,
               'servico_nome' => $ct->servico?->nome,
               'tipo_cobranca' => $ct->servico?->tipo_cobranca,
               'valor_contratado' => (float) $ct->valor_contratado,
               'data_contratacao' => $ct->data_contratacao?->toDateString(),
               'data_vencimento' => $ct->data_vencimento?->toDateString(),
               'observacoes' => $ct->observacoes,
               'ativo' => $ct->ativo,
           ]);

       $servicosDisponiveis = Servico::where('ativo', true)
           ->orderBy('nome')
           ->get(['id', 'nome', 'valor_padrao', 'tipo_cobranca']);

       return Inertia::render('Comercial/AtribuirServico', [
           'company' => [
               'id' => $company->id,
               'name' => $company->name,
               'cnpj' => $company->cnpj,
               'cust_id' => $company->cust_id,
               'nicho' => $company->nicho,
               'segment' => $company->segment,
               'email_cliente' => $company->email_cliente,
               'telefone' => $company->telefone,
           ],
           'contratos' => $contratos,
           'servicos_disponiveis' => $servicosDisponiveis,
       ]);
   }
   ```

2. **`routes/web.php`** — adicionar rota dentro do grupo auth:
   ```php
   Route::get('/comercial/atribuir-servico/{company}', [ComercialController::class, 'atribuirServico'])
       ->name('comercial.atribuir-servico');
   ```

3. **`resources/js/Pages/Comercial/AtribuirServico.jsx`** (NOVO) — página dedicada:

   - Bloco "Contratos existentes" — lista cards de cada contrato com servico_nome + valor BRL + datas + status (ativo/inativo). Read-only nesta versão (editar abre form abaixo, opcional)
   - Bloco "Novo contrato" — form com:
     - Select servico (de servicos_disponiveis) — onChange auto-fill valor_contratado com valor_padrao

   - Botões: "Salvar" (POST `/empresas/{id}/contratos-servico`) e "Cancelar" (volta pra `/companies`)
