## Rodada 1 — UAT inicial (screenshot do operador)

Operador identificou 2 problemas:

1. **Cards em excesso** — linha extra de 5 buckets 7/15/30/60/90d era redundante com "Expirando em 30d" no topo
2. **"Empresas totais: 125" não fazia sentido** — não batia com filtros conhecidos (Performance=111, Publicação=202, Polos=177)

**Investigação via SSH tinker:**
- Payload real de `/grants/resumo` é FLAT (não aninhado como CONTEXT presumiu):
  ```json
  {
    "total": 396, "vigentes": 345, "expirados": 51,
    "expirandoEm": {"7d":3, "15d":55, "30d":74, "60d":117, "90d":121},
    "fontes": {
      "contatosCpp":    {"total": 396, ...},
      "baseVendedores": {"total": 1122, ...}
    }
  }
  ```
- Divergência ML calculada: `baseVendedores.total − contatosCpp.total = 726` ✓

**Fix 1 (commit `fecbe72`):**
- `GrantController::index()` mapeia shape real do payload
- Cards renomeados para fonte de verdade remota: Total no ML | Vigentes | Expirando em 30d | Expirados | Sem grant
- "Empresas totais: 125" removido
- Linha extra de 5 buckets removida
- Divergência ML só renderiza quando > 0
- 22/22 testes verdes (payload de teste sincronizado com shape real)

## Rodada 2 — Universo "Sem grant" ignorava 202 empresas MLB

Operador reportou: "Tem as empresas de Polos também que na aba mlb/polos-empresas mostra 177 empresas".

**Investigação via SSH tinker:**
- `mlb_empresas` tem 202 registros (177 são POLOS), praticamente disjuntos de `companies`:
  - 202 mlb_empresas — só **1** tem `company_id` linkado
  - 176/177 POLOS sem `company_id`
  - 169/177 POLOS têm `cust_id` preenchido
- Meu SQL de `no_grant` rodava só em `companies` — 176 POLOS invisíveis

**Fix 2 (commit `f856031`):**
- `GrantController::index()` faz UNION dos 2 universos:
  - (a) `companies` com adman_account_id/ml_store_id/OAuth ML ativo
  - (b) `mlb_empresas` com `cust_id` preenchido
- Match contra `company_grants` via `ml_cust_id` (não `company_id`)
- Dedup por `cust_id` (Company vence quando duplicado)
- 3 testes novos: inclusão MlbEmpresa / exclusão sem cust_id / dedup
- 25/25 testes verdes (152 assertions)
- Prod: `Sem grant = 49 Company + 178 MlbEmpresa - dedup = ~227`
