    - `GRUPO LUCCAUTO` → `LUCCAUTO.COM` aparece na lista de palpites (não é descartado por estar abaixo de um corte), marcado `incerto`.
    - Dois candidatos com pontuação vizinha rebaixam para `incerto` e marcam `ambiguo = true`, mesmo com pontuação alta.
    - Sem nenhum candidato razoável, devolve palpite nulo com `incerto` — nunca inventa empresa.
    - Devolve até 3 melhores candidatos, para a pessoa escolher depois.
  </behavior>
  <action>

    `palpitar(?string $cnpj, ?string $razaoSocial, string $nomeEnvelope): array`
    devolvendo
    `['company_id' => ?int, 'company_nome' => ?string, 'confianca' => 'certo'|'provavel'|'incerto', 'pontuacao' => float, 'ambiguo' => bool, 'candidatos' => [ ['company_id','nome','pontuacao'], ... ]]`.

    Ordem de tentativa (TAB-05, D-05):
    1. **CNPJ** (só 10 de 201 empresas têm, mas quando tem é a única certeza) → `certo`.
    2. **Razão social** normalizada idêntica (4 de 201) → `certo`.
    3. **Nome**: extrair o nome do cliente de dentro do nome do envelope (tirar os prefixos medidos
       `contrato_gestao_ads_meli_`, `Contrato Gestao de Ads ECF - `, `Contrato Gestão de ADS _ ECF - `),
       normalizar (minúsculas, sem acento, sem pontuação, sem sufixos societários `ltda`, `me`, `epp`,
       `eireli`, `sa`) e pontuar contra `companies.name` + `companies.razao_social` com
       `similar_text()` em porcentagem.

    Régua de confiança — ⚠️ **a parte que protege dinheiro**:
    - `certo` só por CNPJ ou razão social exata. **Similaridade de nome nunca produz `certo`**, por
      mais alta que seja.
    - `provavel` exige pontuação ≥ 85 **e** distância ≥ 15 pontos para o segundo colocado.
    - Todo o resto é `incerto`, inclusive pontuação alta com segundo colocado colado (`ambiguo = true`).
    - Não existe corte que descarte candidato: `GRUPO LUCCAUTO` → `LUCCAUTO.COM` (61%) estava CERTO
      e teria sido jogado fora por um corte em 70. Devolver os 3 melhores sempre, deixando a decisão
      para a pessoa.

    *este casamento erra parecendo acerto — a régua é conservadora de propósito.*
