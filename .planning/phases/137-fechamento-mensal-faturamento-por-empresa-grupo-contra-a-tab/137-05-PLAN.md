Criar `App\Services\Fechamento\FechamentoSnapshotWriter` com a constante pública
`ORIGEM_CONSOLIDAR_MES = 'consolidar_mes'` e um método público:

`sync(Carbon $mes, array $linhasEmpresa, array $linhasGrupo, string $origem, ?int $reconsolidadoPor = null, ?string $motivo = null): array`

Comportamento, todo dentro de um único `DB::transaction`:
1. Normaliza `$mesStr = $mes->copy()->startOfMonth()->toDateString()`.
2. Detecta congelamento: existe alguma linha em `fechamento_snapshots` com
   `whereDate('mes_referencia', $mesStr)` e `origem = ORIGEM_CONSOLIDAR_MES`, com `lockForUpdate()`.
3. Se congelado e `$motivo` for nulo ou string vazia, lança
   `\RuntimeException` com a mensagem `'Competência já fechada — informe o motivo da
   reconsolidação.'` — divergência DELIBERADA do molde do Desempenho, que deixa a origem oficial
   ignorar a trava em silêncio. D-12 revisado exige registro de quem, quando e por quê.
4. Se congelado e há motivo, monta o payload anterior lendo TODAS as linhas de
   `fechamento_snapshots` e `fechamento_grupo_snapshots` daquela competência (`toArray()`) e insere
   uma linha em `fechamento_reconsolidacoes` com `mes_referencia`, `reconsolidado_por`, `motivo`,
   `origem` e `snapshot_anterior = ['empresas' => [...], 'grupos' => [...]]`.
5. Upsert de empresa: para cada item de `$linhasEmpresa` (array já montado pelo comando, com as
   chaves das colunas de `fechamento_snapshots`), busca por `where('company_id', ...)` +
   `whereDate('mes_referencia', $mesStr)` e faz `fill()+save()` ou `create()`. NUNCA usar
   `updateOrCreate(['mes_referencia' => $mesStr])` direto: o cast `date` grava datetime completo e a
   comparação com a string crua nunca casa (armadilha documentada no writer do Desempenho).
   `origem` e `gerado_em` (`now()`) são gravados em toda linha.
6. Prune de empresa: apaga as linhas daquela competência cujo `company_id` não está no conjunto
   recebido — convergir para o conjunto atual, nunca insert-only.
7. Repete 5 e 6 para `fechamento_grupo_snapshots` usando `company_group_id`.
8. Devolve `['empresas_upserted' => int, 'empresas_pruned' => int, 'grupos_upserted' => int,
   'grupos_pruned' => int, 'reconsolidado' => bool]`.

Este é o ÚNICO ponto de escrita das duas tabelas de snapshot em todo o projeto — nenhum controller
ou comando pode chamar `updateOrCreate` nelas diretamente. Registrar isso no docblock, em pt-BR.

`Carbon::now()->subMonthNoOverflow()->startOfMonth()`. Recusa mês futuro com exit code 1.

Passo 1 — conjunto: `Company::where('active', true)` com eager loading de
`contratosServico` (ativos, com `servico`) e `grupo`. Passo 2 — faturamento:
