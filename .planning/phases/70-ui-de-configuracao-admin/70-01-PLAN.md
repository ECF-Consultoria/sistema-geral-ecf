Research §4 (v15-nps-templates-schema.md) define precedência dos templates:

- Templates aplicáveis a uma empresa: `WHERE active=true AND EXISTS(pivot servico_id da empresa)` → maior priority vence
- Fallback global: `is_default=true` (seed NPS Padrão, criado pelo Plan 68-03)
- Unique index parcial em `is_default` (Plan 68-04) garante exatamente 1 default no banco — a UI admin nunca deve permitir criar OU converter template em default (isso quebraria o invariante)

**Regra de segurança:** O template com `is_default=true` (seed NPS Padrão) NUNCA pode ser desativado nem excluído — ele é o fallback do `NpsTemplateService::resolveForCompany` (Phase 69, Plan 69-01). Se cair, `RuntimeException` explode em produção. Guard obrigatório no `update()` e `toggleActive()`.
