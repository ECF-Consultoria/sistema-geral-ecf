Research §4 (v15-nps-templates-schema.md):
- Precedência: priority DESC + is_default fallback (já implementado no Plan 69-01)
- Empresa com [Gestão, Mentoria] recebe template de maior priority entre aplicáveis
- Empate priority → menor id determinístico
- Nenhum aplicável → fallback is_default (seed NPS Padrão)

**Implicação para "empresas afetadas":** para saber quais empresas receberiam ESTE template, precisamos SIMULAR o resolveForCompany() para cada empresa ativa e ver quais retornam este id. Não podemos usar apenas "empresas com serviço no pivot" porque:
- Empresa A pode ter serviço X em comum COM ESTE template, mas outro template com maior priority já cobre X → não receberia ESTE
- Empresa B pode não ter serviço no pivot → cai no is_default (se ESTE for o default, ainda receberia)

**Perf guard:** carteira tem centenas de empresas — limitar consulta a 100 empresas máximo, com aviso "mostrando primeiras 100 de N".

```php
public function syncServicos(SyncNpsTemplateScopesRequest $request, NpsTemplate $template)
{
    $ids = $request->validated()['servicos'] ?? [];
    $template->servicos()->sync($ids);
    $count = count($ids);
    return back()->with(
        'success',
        $count === 0
            ? 'Template desassociado de todos os serviços.'
            : "Template agora vale para {$count} " . ($count === 1 ? 'serviço.' : 'serviços.')
    );
}
```

`sync()` do BelongsToMany do Laravel é atomic (transação implícita) e faz insert/delete só das diferenças — safe para concurrent edits.

```php
public function empresasAfetadas(NpsTemplate $template, \App\Services\Nps\NpsTemplateService $service)
{
    // Base: empresas ativas com pelo menos 1 contrato ativo — evita simular sobre empresas dormentes.
    $companies = \App\Models\Company::query()
        ->whereHas('contratosServico', fn($q) => $q->where('ativo', true))
        ->orderBy('name')
        ->limit(100)  // perf guard — carteira grande
        ->get(['id', 'name']);

    $totalAtivas = \App\Models\Company::whereHas('contratosServico', fn($q) => $q->where('ativo', true))->count();

    $afetadas = [];
    foreach ($companies as $company) {
        try {
            $resolved = $service->resolveForCompany($company);
            if ($resolved->id === $template->id) {
                $afetadas[] = ['id' => $company->id, 'name' => $company->name];
            }
        } catch (\RuntimeException $e) {
            // Empresa sem template aplicável e sem is_default fallback (situação anômala Phase 69-01) — ignora aqui.
            continue;
        }
    }

    return response()->json([
        'template_id'  => $template->id,
        'count'        => count($afetadas),
        'empresas'     => $afetadas,
        'sampled_from' => $companies->count(),
        'total_ativas' => $totalAtivas,
        'truncated'    => $totalAtivas > 100,
    ]);
}
```

**Retorno é JSON** (não Inertia) porque este endpoint é chamado via `axios/fetch` da UI Plan 70-05 sob demanda (ex: quando admin muda seleção de serviços no picker). Não faz sentido re-renderizar a página inteira.

**Perf:** LIMIT 100 empresas + iteração loop — se resolveForCompany fizer 3 queries cada, dá 300 queries no pior caso. Em v15.1 podemos otimizar com batch resolveForCompanies, mas pra v15.0 é aceitável (endpoint chamado só quando admin abre picker de serviços).
</action>

```php
public function preview(PreviewNpsTemplateRequest $request)
{
    $validated = $request->validated();

    // Ordena perguntas pela ordem do array vindo do form (respeita a UI); ordena options por peso ASC
    // para consistência visual (o form pode ter deixado desordenado durante edição).
    $perguntasNormalizadas = collect($validated['perguntas'])->map(function ($p, $idx) {
        return [
            'ordem'       => $idx + 1,
            'texto'       => $p['texto'],
            'tipo'        => $p['tipo'],
            'dimensao'    => $p['dimensao'],
            'obrigatoria' => $p['obrigatoria'] ?? true,
            'options'     => collect($p['options'] ?? [])->map(fn($o, $j) => [
                'ordem' => $j + 1,
                'label' => $o['label'],
                'peso'  => $o['peso'],
            ])->values()->all(),
        ];
    })->values()->all();

    return response()->json([
        'template' => [
            'nome'      => $validated['nome']      ?? '(sem título)',
            'descricao' => $validated['descricao'] ?? null,
            'perguntas' => $perguntasNormalizadas,

}
```
