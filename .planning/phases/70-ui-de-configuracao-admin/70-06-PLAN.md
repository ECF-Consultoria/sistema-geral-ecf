   - Assert `active=true` continua no banco

6. **`test_non_admin_recebe_403_em_todas_as_rotas_de_templates()`:**
   - actingAs consultor
   - Tenta GET index → 403
   - Tenta POST store → 403
   - Tenta PUT update de template válido → 403
   - Tenta PATCH toggle-active → 403
