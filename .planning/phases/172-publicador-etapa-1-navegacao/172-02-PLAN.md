```php
$programaQuery = $request->query('programa');
if ($programaQuery !== null) {
    $programa = in_array($programaQuery, ProgramasPublicadorService::PROGRAMAS, true)
        ? $programaQuery
        : 'polos';
    session(['publicador.ultimo_programa' => $programa]);
} else {
    $programa = (string) session('publicador.ultimo_programa', 'polos');
    if (! in_array($programa, ProgramasPublicadorService::PROGRAMAS, true)) {
        $programa = 'polos';
    }
}
```

Isto preserva o comportamento atual (query `?programa=` sempre manda, valor
inválido cai em `polos`) e ACRESCENTA: (1) toda visita com `?programa=` válido

em `polos` se a sessão estiver vazia. A chave de sessão `publicador.ultimo_programa`
é nova — não reusa nenhuma chave existente.
