<interfaces>
A criar (namespace `App\Services\Portal\Estrutura\Geracao`, todas `final class` com métodos estáticos):

ChaveDeComposicao
- `de(array $itens): string` — `$itens` = `array<int variacao_id, int quantidade>`; `ksort`; formato `v{id}*{qtd}` unido por `+`. Ex.: [30 => 4, 12 => 1] → 'v12*1+v30*4'.
- `valida(string $chave): bool` — regex `/^v\d+\*\d+(\+v\d+\*\d+){0,2}$/` E `strlen ≤ 100` (coluna `chave` varchar(100)).
- `itens(string $chave): array<int, int>` — inverso de `de`; chave inválida → [].

Quantidades
- `MENSAGEM` = 'Use números inteiros de 2 a 999, separados por vírgula.'
- `ler(?string $texto, string $campo = 'quantidades', int $maxItens = 8): ?array` — null ou só espaços → null (herda); '0' → [] (nenhuma); "2, 4, 6" / "6;2 4" → [2, 4, 6] (separadores vírgula, ponto e vírgula ou espaço; únicos; ordenados). Inválido (não inteiro, < 2, > 999, mistura de 0 com outros, mais de `$maxItens`) → `ValidationException::withMessages([$campo => MENSAGEM])`.
- `paraTexto(?array $lista): ?string` — null → null; [] → '0'; [2, 4, 6] → '2, 4, 6'.
- `doTipo(?string $texto): array` — nível do TIPO: null, '' ou '0' → []; senão `ler($texto)`.
- `efetivas(?array $doProduto, array $doTipo): array` — `$doProduto` não nulo vence (inclusive [] = nenhuma); senão `$doTipo`.

VariacoesEmParalelo
- `casar(array $a, array $b): list<array{0: array, 1: array}>` — variação = `['id' => int, 'ordem' => int, 'eixo' => ?string, 'valor' => ?string, ...]` (as chaves extras passam intactas).
</interfaces>
