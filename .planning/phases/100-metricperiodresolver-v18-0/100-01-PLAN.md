## Contrato (assinatura e shape) — cravar fiel ao plano §554-570

Assinatura: `resolve(array $filtros): array`.

`$filtros` aceita:
- `period_key`: `current_month` | `last_closed_month` | `YYYY-MM` (ex.: `2026-06`) | `custom`
- `custom` exige `start` e `end` (strings `YYYY-MM-DD`), datas inclusivas nas duas pontas
- `data_fresh_until` (opcional, string `YYYY-MM-DD`): último dia confiável consolidado pela fonte. **INPUT** — o resolver NÃO consulta banco/Adman. Só faz sentido em `current_month`. Default quando ausente = **hoje** (o próprio dia corrente em `America/Sao_Paulo`). Clamp: se informado > hoje → usa hoje; se < `current_start` → usa `current_start`.

Retorno (14 chaves, SEMPRE presentes, exatamente estes nomes):
`mode`, `period_key`, `current_start`, `current_end`, `baseline_start`, `baseline_end`, `days_count`, `comparison_mode`, `timezone`, `data_fresh_until`, `bonus_payment_month`, `bonus_competence_month`, `is_current_month`, `is_closed`.
- Datas (`*_start`/`*_end`/`data_fresh_until`) como string `YYYY-MM-DD`, inclusivas.
- `bonus_payment_month`/`bonus_competence_month` como `YYYY-MM` ou `null` (só preenchidos no modo oficial/bônus).
- `timezone` sempre `'America/Sao_Paulo'`.

## Matemática exata por modo (não simplificar — regras distintas)

1. **current_month → `mode='operational'`, `comparison_mode='same_interval_previous_month'`**
   - `current_start` = dia 1 do mês corrente; `current_end` = `data_fresh_until` (default hoje).
   - baseline = MESMO intervalo de dias no mês calendário anterior, alinhado por dia: `baseline_start` = dia 1 do mês anterior; `baseline_end` = mês anterior no mesmo dia-do-mês de `current_end`.
   - **Clamp de dia inexistente:** se o dia-do-mês de `current_end` não existe no mês anterior (ex.: 31/03 atual → fevereiro não tem 31), usar o ÚLTIMO dia do mês anterior.
   - `is_current_month=true`, `is_closed=false`, `bonus_*=null`, `data_fresh_until` = `current_end`.

2. **last_closed_month → `mode='official_bonus'`, `comparison_mode='previous_equal_length_window'`**
   - Competência = último mês fechado relativo a hoje (em julho/2026 → junho/2026).
   - `current_start`/`current_end` = mês calendário completo da competência (`01/06..30/06`).
   - baseline = N dias imediatamente anteriores a `current_start`, N = `days_count`: `baseline_end` = `current_start` − 1 dia; `baseline_start` = `baseline_end` − (`days_count` − 1) dias. (Junho 30 dias → `31/05` e `02/05`.)
   - `bonus_competence_month` = competência `YYYY-MM`; `bonus_payment_month` = mês seguinte à competência (= mês corrente quando se está no mês seguinte ao fechado).
   - `is_current_month=false`, `is_closed=true`, `data_fresh_until`=`current_end`.

3. **YYYY-MM (mês específico) → `mode='closed_period'`, `comparison_mode='previous_equal_length_window'`**
   - `current` = mês calendário completo selecionado; baseline = mesma regra de janela-de-mesmo-tamanho do item 2 (Maio/2026: `01/05..31/05` vs `31/03..30/04`).
   - `bonus_*=null` (bônus oficial é SÓ `last_closed_month`). `is_closed` = (último dia do mês selecionado < hoje). `is_current_month` = (mês selecionado == mês corrente). `data_fresh_until`=`current_end`.

4. **custom → `mode='closed_period'`, `comparison_mode='previous_equal_length_window'`**
   - `current_start`=`start`, `current_end`=`end`; `days_count` = `end`−`start`+1 (inclusivo).
   - baseline = N dias imediatamente anteriores a `start`, N=`days_count` (custom `01/06..15/06`, 15 dias → `17/05..31/05`).
   - `bonus_*=null`, `is_current_month=false`, `is_closed` = (`end` < hoje), `data_fresh_until`=`current_end`.

## Notas de fronteira
