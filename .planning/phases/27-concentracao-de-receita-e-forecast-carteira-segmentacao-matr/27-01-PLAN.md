## Riscos residuais (documentados — não bloqueiam o plan)

**R-01: Shape de carteiraSegmentacao pode vir diferente do esperado (chaves diferentes)**
- Mitigação: try/catch global captura. Fallback shape vazio em props. Documentar em comentário do controller pra ajuste futuro caso o parceiro mude o schema.

**R-02: 50 sellerMetricasMensal em cold cache ~30s — pode timeout do PHP**
- Mitigação: ECF Drive responde rápido (<300ms cada). 50 × 600ms ≈ 30s — abaixo do default `max_execution_time = 60s` do PHP CLI/FPM. Em prod com FPM customizado já validado (Phase 24/25 fizeram cargas similares). Cache 1h cobre 99% dos casos pós-primeiro acesso.

**R-03: Algum cust_id do ranking não tem `tgmv_lc` válido (string vazia)**
- Mitigação: `(float)$tgmvLc` em PHP retorna 0.0 pra string vazia. CV de zeros = null (degenerado mas seguro). Seller é incluído na lista de vacas com null CV — ordenação coloca por último.

**R-04: companies sem `adman_account_id` nem `ml_store_id` (publicação, polo-only) — vacas leiteiras sem link**
- Mitigação: D-H — exibir nome `Lojista #{custId}` sem link. Não-objetivo CONTEXT é ligar a /empresas/{id}/analise-ecf que exige Company local; sellers sem company local mostram o que ECF Drive sabe.

**R-05: Regressão linear sobre 12 meses com 1 mês corrente parcial — slope distorcido**
- Mitigação: CONTEXT pitfall 2 já documenta limitação MVP. Banner explicativo "Projeção linear simples — não considera sazonalidade." Controller usa `gmvFechado` quando disponível e `gmv` quando não — mesma estratégia do HistoricoChart Phase 24.

**R-06: Forecast com slope NEGATIVO + cenário pessimista pode resultar em valor < 0**
- Mitigação: clamp `max(0, $valor)` no controller antes de renderizar. R$ negativo seria absurdo semanticamente.

**R-07: `grantsExpirandoEm(90)` pode trazer >100 grants — top 10 corta o resto sem alertar**
- Mitigação: Lista top 10 + label "Mostrando 10 de N grants vencendo nos próximos 90d". Phase futura pode adicionar paginação ou link "ver todos" para /grants.

**R-08: shadcn não tem componente Heatmap nativo — fazer tabela HTML semântica**
- Mitigação: `<table><thead/><tbody/></table>` com Tailwind classes. Acessível. Sem dependência nova.

**R-09: `bg-ecf-yellow/{intensidade}` exige valores discretos do Tailwind (5,10,20,30,...,100)**
- Mitigação: usar arbitrary values `bg-[rgba(255,230,0,${pct/100})]` via inline style — mais flexível que classes discretas. Trade-off: 1 inline style por célula. Aceitar.

      ```php
      $n = count($y);
      if ($n < 2) {

      }

      $y = array_map(fn($v) => (float) $v, $y);

      $mean_x = ($n - 1) / 2;
      $mean_y = array_sum($y) / $n;

      $num = 0.0;
      $den = 0.0;
      for ($i = 0; $i < $n; $i++) {
          $num += ($i - $mean_x) * ($y[$i] - $mean_y);
          $den += ($i - $mean_x) ** 2;
      }

      $a = $den != 0 ? $num / $den : 0.0; // slope
      $b = $mean_y - $a * $mean_x;        // intercept

      // R² (coeficiente de determinação) — opcional mas útil em logs futuros
      $ss_tot = 0.0; $ss_res = 0.0;
      for ($i = 0; $i < $n; $i++) {
          $y_pred  = $a * $i + $b;
          $ss_res += ($y[$i] - $y_pred) ** 2;
          $ss_tot += ($y[$i] - $mean_y) ** 2;
      }
      $r2 = $ss_tot > 0 ? 1 - ($ss_res / $ss_tot) : 0.0;

      return ['a' => $a, 'b' => $b, 'r2' => $r2];

      $grantsEnriquecidos = [];
      foreach ($grants as $g) {
          $custId = $g['cust_id'] ?? null;
          $mediaM = $custId && isset($sellersCalculados[$custId])
              ? $sellersCalculados[$custId]['media_mensal']
              : 0;
          // 90 dias = ~3 meses → GMV em risco do seller = media_mensal × 3
          $gmvRiscoSeller = $mediaM * 3;
          $gmvRiscoTotal += $gmvRiscoSeller;
          $grantsEnriquecidos[] = [
              'cust_id'           => $custId,
              'razao_social'      => $g['razao_social'] ?? null,
              'cnpj'              => $g['cnpj'] ?? null,
              'grant_fim'         => $g['grant_fim'] ?? null,
              'dias_para_expirar' => (int) ($g['dias_para_expirar'] ?? 0),
              'media_mensal'      => $mediaM,
              'gmv_risco'         => $gmvRiscoSeller,
          ];
      }

      $grantsTop10 = collect($grantsEnriquecidos)
          ->sortByDesc('gmv_risco')
          ->take(10)
          ->values()
          ->all();

      // ─── 9) Forecast — 3 cenários ───────────────────────────────────────
      // GMV em risco distribuído uniformemente entre os 3 meses (D-F)
      $riscoPorMes = $gmvRiscoTotal / 3;
      $cenarios = array_map(function ($p) use ($riscoPorMes) {
          $base       = $p['y'];
          $otimista   = $base;                                  // 100% renovação
          $cenarioBase = max(0, $base - $riscoPorMes * 0.2);    // 80% renovação (R-06 clamp)
          $pessimista = max(0, $base - $riscoPorMes * 0.4);     // 60% renovação
          return [
              'x'           => $p['x'],
              'otimista'    => $otimista,
              'base'        => $cenarioBase,
              'pessimista'  => $pessimista,
          ];
      }, $projecao);

      $forecast = [
          'historico'     => $historico,             // shape original do parceiro pro chart consumir
          'projecao'      => $cenarios,
          'gmvRisco'      => $gmvRiscoTotal,
          'grantsTop10'   => $grantsTop10,
          'coef'          => $coef,                  // {a, b, r2} — útil pra debug/tooltip
          'totalGrants'   => count($grants),         // sinaliza no JSX "Mostrando 10 de N"
      ];

      return Inertia::render('Concentracao/Index', [
          'matriz'   => $matriz,
          'forecast' => $forecast,
          'vacas'    => $vacas,
          'erro'     => null,
      ]);
      ```
