<objective>
Construir a Tela 1: o painel operacional que responde "o que está travando, há quantos dias e de
quem é a bola".

Purpose: SC-11 é uma rejeição, e a tela precisa honrar a rejeição. O Polos responde `feitos/total`
com prazo fixo de 5 dias para tudo; aqui nenhuma barra de progresso pode ser o elemento visual
principal de nenhuma visão. A resposta é textual e nominal: o passo, os dias, o dono.

O estado mais fácil de errar é "aguardando coleta". Enquanto o job de acervo não voltou, a tela
**não pode** renderizar "0 anúncios inativos" — o valor só aparece quando o passo conclui. E se a
coleta passar do tempo esperado, a tela precisa dizer isso em vez de deixar o operador achar que
está tudo bem.

Output: página do painel com dois níveis, chip de situação, detalhe dos 13 passos, item de menu.
</objective>

**O que esta tela recusa fazer:** `Progress` (`Components/ui/progress.jsx`) não pode ser o elemento
visual principal de nenhuma visão. Não é proibido como componente (cabe como detalhe secundário,
ex. dentro de um tooltip), mas nunca como a resposta a "como está o onboarding".

**Nível 1 — lista agrupada por empresa (D-01).** Cada card de empresa:
- Nome + badge do(s) serviço(s) com onboarding ativo
- **Chip único de situação**, com 6 valores e rótulos exatos:
  | valor | rótulo | tom |
  |---|---|---|
  | `rascunho` | "Rascunho — aguardando responsável" | neutro, borda tracejada (`text-white/30 bg-white/[0.04]`) |
  | `vencido` | "Vencido" | `text-red-300 bg-red-500/10 border-red-500/20` |
  | `aguardando_cliente` / `aguardando_interno` / `aguardando_sistema` | "Aguardando cliente/interno/sistema" | `text-amber-300 bg-amber-500/10 border-amber-500/20` |
  | `coletando` | "Coletando dados" | `text-sky-300 bg-sky-500/10 border-sky-500/20` |
  | `pronto_para_concluir` | "Pronto para concluir" | esmeralda com aviso |
  | `concluido` | "Concluído" | `text-emerald-300 bg-emerald-500/10 border-emerald-500/20` |
- **O passo que mais trava**: título + dono + "há X dias" + "{sla}d"
- Responsável (`Avatar` + nome) ou, em rascunho sem confirmação, "Sem responsável" + CTA

  componente `tone`-based e cross-domínio, **importar direto**, não recriar

**"Pronto para concluir" (D-15):** quando tudo que não é administrativo terminou e só falta
"Confirmação de pagamento", a tela não pode dizer "Concluído" nem esconder a pendência na lista
genérica — o chip próprio existe para separar "mapeamento parado" de "questão administrativa
parada", que têm dono e urgência diferentes.

**Nível 2 — detalhe** (drawer lateral ou página própria; este contrato não exige uma sobre a
outra). Lista dos 13 passos, cada linha com:
| Campo | Conteúdo |
|---|---|
| Título | `titulo` do passo |
| Badge de **dono** | `cliente` sky-300 · `interno` violet-300 (+ setor, ex. "interno · financeiro") · `sistema` ecf-yellow/70 |
| Selo de **automação** (separado do dono, D-19) | ícone `Zap` accent **só** quando `tem_auto_fonte` — aparece inclusive em passo `dono=cliente`. **Obrigatório** `aria-label="Passo verificado automaticamente pelo sistema"` + `title` com o mesmo texto (é o único indicador de status sem rótulo textual ao lado) |
| Estado | um dos 7 da paleta semântica — **nunca** um número solto tipo "0/1" |
| Dias | "há X dias" contado de `disponivel_em`; passo **bloqueado não mostra contador** |
| SLA | "{sla_dias}d" ao lado do contador, só em passos abertos-e-parados |
| Dependências | bloqueado → "Aguarda: {títulos}" com ícone `Lock` |
| Condição | nota discreta "Só se aplica quando: {descrição legível}" — **nunca** a expressão crua |

**Terceiro estado — "aguardando coleta" (4 regras sem exceção):**
1. **Nunca** renderizar valor numérico definitivo (ex. "0 anúncios inativos") enquanto o status for
   `aguardando_coleta` — o número só aparece quando vira `concluido`
2. Ícone `RefreshCw` com `animate-spin` (Tailwind core; nenhum keyframe novo)
3. Texto "Coletando dados automaticamente…" — sem contagem de dias alarmante, mas com timestamp
   discreto "iniciado há X min"
4. **Watchdog:** com `coleta_demorando === true`, trocar para "Coleta demorando mais que o
   esperado" com `AlertTriangle` em tom âmbar
5. Estado `indeterminado`: `AlertTriangle` âmbar + a copy exata "Não foi possível confirmar agora —
   vamos tentar de novo automaticamente." (**nunca** a palavra "Erro", nunca soar como falha de
   quem está olhando)

**Item de navegação:** grupo "Comercial", ícone `ListChecks`, gate `permission: 'core.onboarding'`
