<objective>
Construir a Tela 2 do `135-UI-SPEC.md`: o builder de template, onde o admin monta os passos e
publica versões.

Purpose: é aqui que a D-09 vira coisa visível. `auto_fonte` **precisa parecer** fechado — a
ausência de qualquer campo de texto livre ao lado do Select é o que comunica isso, e cada opção
mostra rótulo legível ("Automático — `adman_account_id` preenchido") em vez do nome da classe PHP,
com uma linha de ajuda dizendo o que o resolver verifica e se roda em job. O admin que monta o
template precisa saber que alguns passos levam minutos para fechar.

E é aqui que duas armadilhas registradas do projeto mordem: `<SelectItem value="">` do Radix
derruba o render inteiro (tela preta), e página React de re-export puro some do manifest do Vite —
a rota morre em runtime, não no build.

Output: página Index.jsx com dois modos, editor de passo, 2 dialogs, banner de ciclo, bundle
recompilado.
</objective>
