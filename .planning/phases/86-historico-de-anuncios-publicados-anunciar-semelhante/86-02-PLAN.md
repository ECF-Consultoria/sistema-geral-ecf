<decisoes_de_projeto>
**1. `AnunciosHistorico.jsx` — o nome `Historico.jsx` já está ocupado.**

`resources/js/Pages/Mlb/Historico.jsx` existe e é o histórico de publicações do módulo MLB **antigo**
(renderizado por `MlbController.php:1266`, com `mlb.destroy` próprio). Nome novo `AnunciosHistorico`,
irmão de `AnunciosEmpresas.jsx` no mesmo módulo. O 86-01 renderiza exatamente essa string.

**2. `linkAnuncioMl` sai para um módulo de funções puras — não é cópia da linha do wizard.**

A decisão travada 4 manda **reusar** a montagem do commit 9e5a640, que hoje é um template literal
inline em `AnunciarML.jsx:2467`:
`https://produto.mercadolivre.com.br/MLB-${String(r.ml_item_id).replace(/^MLB-?/i, '')}`.

Copiar essa linha para a página nova criaria **duas** fontes do formato da URL — e a próxima
correção arrumaria uma só. Extrair para função pura é o padrão já estabelecido neste módulo
(`gradeMassaUtils.js` + `tests/js/gradeMassaUtils.test.js`, "fonte única" da Phase 85) e dá **teste
de comportamento de verdade**, não gate estrutural.

O `replace(/^MLB-?/i, '')` **não** é enfeite: `ml_item_id` vem do ML como `MLB1234567890`, e sem o
strip a URL viraria `MLB-MLB1234567890` — 404. É o bug que o 9e5a640 consertou; o teste o tranca.

Quem reescreve `AnunciarML.jsx:2467` para importar a função é o **plano 03** (é ele que já abre esse
arquivo — evita dois planos disputando um arquivo de 2582 linhas).

**3. Cards, não tabela.**

`AnunciosEmpresas.jsx` (mesmo módulo, mesmo autor) é grid de cards, e o item aqui tem **foto de capa**
— o ativo mais reconhecível de um anúncio. Uma tabela esconderia a foto numa coluna de 40px. Grid
responsivo, mesmas classes do irmão (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`).

**4. Busca no servidor, com debounce — não filtro local.**

A lista é **paginada** (24/página): filtrar em JS só filtraria a página atual e mentiria para o
publicador ("não achei" quando está na página 3). `router.get` com `?busca=`, `preserveState` para o
input não perder o foco a cada tecla, debounce de 400ms para não disparar uma requisição por
caractere. O `historico()` ecoa o termo em `filtros.busca` — o input nasce preenchido ao voltar da
página 2.
</decisoes_de_projeto>
