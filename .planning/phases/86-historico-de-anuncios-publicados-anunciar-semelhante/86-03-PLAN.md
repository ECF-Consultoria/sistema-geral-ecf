<decisoes_de_projeto>
**1. O front redireciona; a rota de duplicar não muda uma linha.**

A decisão travada 3 é explícita: se precisar de ajuste em `duplicarComoTemplate`, faça **o mínimo e
sem quebrar o consumidor atual** — `AnunciarML.jsx:1355` chama a rota e espera JSON `{ok, rascunho}`.

O ajuste necessário é **zero**. O histórico faz o mesmo POST, lê o mesmo `{ok, rascunho}` e então
**ele** navega: `router.get(route('mlb.anuncios.wizard', { company, rascunho: novo.id }))`. Trocar a
resposta por um redirect quebraria o wizard, que hidrata in-place e **não** navega. Duas telas, dois
comportamentos, uma rota — porque a rota devolve dado, não navegação.

**2. Por que redirect e não abrir o wizard "do zero" com o payload no estado.**

Decisão travada 2: "abre no WIZARD individual". O rascunho **já existe no banco** quando o POST
retorna — é uma linha real com id. Levar o payload pela URL/estado criaria um segundo caminho de
hidratação (o wizard já tem `abrirRascunho`) e o autosave do wizard, ao disparar, criaria um
**segundo** rascunho. Redirecionar com o id reusa o caminho que já existe e já é testado.

**3. A auto-abertura reusa `abrirRascunho`, não `hidratarDoRascunho`.**

`hidratarDoRascunho` (`AnunciarML.jsx:1028`) preenche só título/preço/estoque/descrição/dimensões.
`abrirRascunho` (`:1058`) é a função completa: `limparFormulario()`, `setRascunhoId(r.id)`,
`hidratarDoRascunho(r)`, restaura `listing_type_id`, os atributos do item em `valores`, e busca os
atributos da categoria. Um "semelhante" aberto pela função errada perderia os atributos — exatamente
o que o publicador não quer redigitar. É a mesma função que o botão "Abrir" da lista de rascunhos já
chama (`:2507`).

**4. O clone está garantido na prop `rascunhos`.**

`wizard()` carrega `MlAnuncioRascunho::where('company_id', ...)->latest()->limit(50)`. O clone acaba
de ser criado → é o mais recente → está sempre no topo dos 50. Não é preciso endpoint novo nem
mexer no `limit`.

**5. O wizard passa a importar `linkAnuncioMl`.**

`AnunciarML.jsx:2467` tem a URL inline. Com a página nova importando a fonte única (86-02), deixar o
wizard com a cópia manteria **duas** fontes do formato — o que a decisão travada 4 quer evitar. Este
plano é o único que abre `AnunciarML.jsx`; a troca sai de graça aqui e não custa um plano só para
ela.
</decisoes_de_projeto>

```
// HIST-86-2: o histórico cria o "semelhante" e manda o publicador para cá com ?rascunho=N.
// Abrimos o clone sozinho — ele já vem com título, preço, atributos e fotos do publicado.
// Guarda por ref: abrirRascunho é async e mexe em vários states; sem o ref, o re-render que
// ela mesma provoca reentraria no efeito e sobrescreveria o que o publicador já digitou.
// abrirRascunho fica FORA das deps de propósito (não é useCallback: muda de identidade a
// cada render e re-dispararia o efeito eternamente).
const autoAbertoRef = useRef(false);
useEffect(() => {
    if (autoAbertoRef.current || !abrirRascunhoId) return;
    const alvo = rascunhos.find((r) => r.id === abrirRascunhoId);
    // Id que não está na prop (rascunho de outra empresa, ou apagado): ignora em silêncio —
    // a prop rascunhos já é filtrada por company_id no wizard(), então nada vaza por aqui.
    if (!alvo) return;
    autoAbertoRef.current = true;
    abrirRascunho(alvo);
    // eslint-disable-next-line react-hooks/exhaustive-deps
}, [abrirRascunhoId, rascunhos]);
```
