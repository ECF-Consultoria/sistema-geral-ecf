    ```
    public function fetchDealLineItems(string $dealId): array
    ```

    Implementação (passos):

    1. **Chamada 1 — listagem de associations:**
       - Endpoint: GET self::BASE . "/crm/v3/objects/deals/{$dealId}/associations/line_items"
       - Header: Http::withToken($this->token)
       - Se `!$res->ok()` → retornar `[]` (resiliente, mesma estratégia de fetchAssociatedCompanyId)
       - Extrair IDs via $res->json('results') ?? []; map para `(string) $r['id']` filtrando null/vazio
       - Se lista vazia → retornar `[]`

    2. **Chamada 2..N — detalhes de cada line item:**
       - Para cada $id, GET self::BASE . "/crm/v3/objects/line_items/{$id}" com query `properties=name,price,quantity,hs_product_id,recurringbillingfrequency`
       - Se `!$res->ok()` → Log::channel('ecf-webhooks')->warning("[HubSpot Webhook] Falha ao buscar line item", ['deal_id' => $dealId, 'line_item_id' => $id, 'status' => $res->status()]); continue;
       - Senão, $props = $res->json('properties') ?? [];
       - Acumular em `$out[]` array com shape:
         ```
         [
           'id' => $id,
           'name' => $props['name'] ?? null,
           'price' => isset($props['price']) && is_numeric($props['price']) ? (float) $props['price'] : null,
           'quantity' => isset($props['quantity']) && is_numeric($props['quantity']) ? (int) $props['quantity'] : null,
           'hs_product_id' => isset($props['hs_product_id']) ? (string) $props['hs_product_id'] : null,
           'recurringbillingfrequency' => $props['recurringbillingfrequency'] ?? null,
         ]
         ```

    3. Retornar `$out`.

      2. GET /crm/v3/objects/line_items/{id}?properties=... — detalhes de cada item

    Resiliente: 4xx/5xx em associations retorna []; falha em GET /line_items/{id}
    individual loga warning e pula o item (segue com os demais). Deal sem line
    items é cenário válido (retorna [] silencioso).

    Consumido pelo HubspotWebhookController (Plan 37-04) após criarEmpresa para
    materializar contratos_servico em DB::transaction.

    @return array<int, array{id: string, name: ?string, price: ?float, quantity: ?int, hs_product_id: ?string, recurringbillingfrequency: ?string}>"

    Adicionar `use Illuminate\Support\Facades\Log;` no topo do arquivo (verificar se já está; senão, adicionar).
