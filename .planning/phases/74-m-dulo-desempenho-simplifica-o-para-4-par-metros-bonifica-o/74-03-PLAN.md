Métodos privados:
- `computeUniverso(User $user, Carbon $mes): array` — verifica carteira ativa no mês; retorna shape mínimo com sem_carteira=true+motivo pt-BR "Sem carteira em {mesExtenso}/{ano}" quando vazia.
- `computeNpsMedio(User $user, Carbon $mes): float` — soma notas NPS por dimensão. Dimensão: `estrategista` se `$user->isMentor()`, senão `analista` (mesmo mapeamento do PortfolioScoreService legado + Phase 73 dual-path). Filtra `NpsSurvey where company_id IN carteira AND status='completed' AND completed_at BETWEEN mes.startOfMonth AND mes.endOfMonth`. Para cada `NpsResponse` associada, obtém score via `NpsScoreCalculator::compute($response, $dim)` OU fallback direto para `score_estrategista/score_analista` legacy quando calculator retorna null (dual-path Phase 72/73). Média aritmética das notas obtidas. Se nenhuma resposta no mês, retorna `0.0` (penaliza, decisão diretoria DESEMP-03).
- `computeVarFaturamento(User $user, Carbon $mes): ?float` — para cada empresa ativa da carteira do user no mês, resolver provider via `MetricsProviderFactory::caseFor($company)`. Se `case === 'none'`, pular empresa. Descartar empresas **NOVAS** (associadas via `company_users` há menos de 2 meses — usar `company_users.created_at` como proxy). Para cada empresa qualificada, obter `rev_atual` (soma revenue do mês) e `rev_anterior` (soma revenue do mês-1) via provider primário (ML se `caseFor in ['ambos','so-ml']` senão Adman). Descartar se `rev_anterior <= 0`. Retornar `AVG((rev_atual - rev_anterior) / rev_anterior * 100)` das restantes ou `null` se nenhuma qualifica.
- `computeVarMargem(User $user, Carbon $mes): ?float` — mesma iteração, mas fonte SEMPRE `AdmanMetric` diretamente (spec DESEMP-05 conhece o gap ML sem custo). Query `SUM(contribution_margin) per company_id whereBetween reference_date [mes.start, mes.end]` vs `[mes-1.start, mes-1.end]`. Descartar `margem_anterior <= 0`. Retornar `AVG((atual - anterior) / anterior * 100)` ou `null`.
- `computeAbsenteismo(User $user, Carbon $mes): ?float` — retorna `null` sempre nesta phase (DESEMP-06 standby). Método existe para futuro plumbing.
- `computeNotaFinal(?float $nps, ?float $fat, ?float $margem): ?float` — filtra componentes não-nulos, retorna `null` se todos nulos, senão `round(sum/count, 2)`. Absenteísmo NÃO entra (DESEMP-02).
- `classificarFaixa(float $nota): ?string` — delega para `BonusFaixa::classificar($nota)?->slug`. Cache in-memory por request via propriedade `?Collection $faixasCache` para evitar re-query em loops (5 users no ranking = 1 query).
- `promoverPor2MesesConsecutivos(User $user, Carbon $mes, string $faixaAtual): array` — retorna `['faixa' => string, 'promovida' => bool]`. Regra DESEMP-08: se `$faixaAtual === 'intermediario'`, consultar `DesempenhoScoreSnapshot::where('user_id', $user->id)->where('mes_referencia', $mes->copy()->subMonth()->startOfMonth()->toDateString())->first()`. Se `$prev?->classificacao === 'intermediario'`, promover para `'maximo'` + promovida=true. Também: se `$faixaAtual === 'intermediario'` e nota corrente `>= 5.00`, promover para `'maximo'` (regra suplementar spec DESEMP-08 target).
- `mesExtenso(Carbon $mes): string` — helper pt-BR: "julho/2026", "agosto/2026" etc. Usar `$mes->locale('pt_BR')->translatedFormat('F/Y')`.

Observações críticas:
1. TODAS as queries de `AdmanMetric` devem usar `whereDate` (não `where`) para robustez SQLite (mesmo padrão do `SnapshotDesempenhoScores` linha 79).
2. TODAS as somas de `revenue`/`contribution_margin` são via SQL agregado (`selectRaw` + `groupBy`) — NÃO percorrer rows em loop PHP para não estourar memória com muitas empresas.
3. Empresas com `active = false` são SEMPRE excluídas do universo (mesmo padrão v1 linha 76).
4. Cache in-memory de `BonusFaixa::ativas()->ordenadas()->get()` uma vez por instância do service (invalida entre requests naturalmente).
5. Reuso de `Company::estrategista()`/`consultor()` ou `User->companies()` conforme padrão existente do projeto.
