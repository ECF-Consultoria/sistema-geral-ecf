## 1. Aviso de link já existente (modal "Gerar link", área NPS)

Aparece quando o flash traz `nps_link_existente`. Reusa o MESMO `linkDialog`/`generatedLink`
já existentes — não criar um terceiro modal.

- Título do modal: **"Já existe um link deste mês"**
- Corpo (texto exato):
  "Esta empresa já tem um link de NPS deste modelo neste mês. Enviar um segundo link pode fazer
  o cliente responder duas vezes. Use o link abaixo."
- O link existente aparece no MESMO bloco copiável do link recém-gerado.
- Botão: **"Copiar link"** (o mesmo já existente).
- Cor de destaque: âmbar (aviso), não vermelho (não é erro do usuário).

Quando é link de grupo já existente, trocar a primeira frase por:
  "Este grupo já tem um link de NPS deste modelo neste mês. Enviar um segundo link pode fazer o
  cliente responder duas vezes. Use o link abaixo."

## 2. Prévia de cobertura do grupo (modal "Gerar link", antes do submit)

Cabeçalho da seção: **"Quem vai receber esta nota"**

Estados (todos obrigatórios):

- **Carregando:** "Verificando as empresas do grupo..." (skeleton/spinner no padrão já usado
  em `carregandoEmpresas`)
- **Grupo qualificado** (nenhuma excluída): bloco verde —
  "Todas as {N} empresas do grupo vão receber a nota que o cliente der."
  Listar os nomes.
- **Grupo parcialmente qualificado:** dois blocos.
  - Verde, título "Vão receber a nota ({N})" — lista de nomes.
  - Âmbar, título "Não vão receber ({M})" — uma linha por empresa, com o motivo:
    - `responsavel_diferente` → "**{empresa}** — o {servico} desta empresa é cuidado por outra
      pessoa ({quem_cuida}). Ela continua com nota 1 no mês até você gerar um link só para ela."
    - `sem_servico_contratado` → "**{empresa}** — não tem {servico} contratado, então este modelo
      de pesquisa não se aplica a ela."
    - `sem_servico_em_comum` → "**{empresa}** — não tem nenhum serviço em comum com as outras
      empresas do grupo neste modelo de pesquisa."
    - `ja_tem_link` → "**{empresa}** — já tem um link deste modelo neste mês. Ela responde pelo
      link dela."
    - `empresa_inativa` → "**{empresa}** — está inativa no sistema."
- **Grupo não qualificado** (nenhuma incluída): bloco âmbar —
  "Nenhuma empresa deste grupo pode receber este link agora. Veja o motivo de cada uma abaixo."
  + lista de motivos + **botão de gerar desabilitado**.
- **Empresa única, sem grupo:** "Esta empresa não faz parte de nenhum grupo. O link vale só
  para ela." (nenhuma prévia de cobertura é buscada)

A prévia é buscada ao ter grupo E modelo escolhidos, no mesmo padrão assíncrono de
`onSelectModelo`. Enquanto a prévia não terminou, o botão de gerar fica desabilitado.

## 3. Motivo na lista de empresas sem link (aba/lista "faltantes" da área NPS)

- Item com `motivo === 'sem_contato'`: badge âmbar **"Sem contato cadastrado"** e o texto
  "Esta empresa não tem e-mail nem WhatsApp cadastrado. Sem isso não dá para enviar a pesquisa —
  e ela fica com nota 1 no mês. Cadastre o contato na página da empresa."
- Item com `motivo === 'sem_link'` e `conta_nota_1 === true`: texto
  "Sem link neste mês — já está contando nota 1."
- Item com `motivo === 'sem_link'` e `conta_nota_1 === false`: texto
  "Sem link neste mês — ainda dá tempo de enviar."
- Se `contadores.contam_nota_1 > 0`, mostrar no topo da lista:
  "{N} empresas estão contando nota 1 por não terem recebido pesquisa neste mês."
