# Phase 119.1 — Estratégia de Validação

> Contrato de validação por fase para amostragem de feedback durante a execução.

---

## Infraestrutura de Teste

| Propriedade | Valor |
|----------|-------|
| **Framework** | PHPUnit 11.x (`phpunit/phpunit ^11.5.50`) + Laravel Feature Tests (`RefreshDatabase`) |
| **Arquivo de config** | `phpunit.xml` |
| **Comando rápido** | `php artisan test --filter=Phase119_1` |
| **Comando full** | `php artisan test` (com filtro — a suíte 100% completa trava, ver abaixo) |
| **Runtime estimado** | ~20s (filtro da fase) |

**Ambiente:** o PHP não está no PATH desta máquina — usar PowerShell com `$env:Path = "C:\xampp\php;$env:Path"`. Testes rodam em SQLite `:memory:`.

**NÃO rodar `php artisan test` sem filtro:** documentado na Fase 116 que a suíte completa trava de forma reproduzível (~50-55%) numa chamada HTTP real não mockada.

---

## Taxa de Amostragem

- **Após cada commit de task:** `php artisan test --filter=Phase119_1`
- **Após cada wave:** `--filter=Phase116` + `--filter=Phase118` + `--filter=Phase119` (hash-gates) + `--filter=Phase119_1`
- **Gate da fase:** os quatro filtros acima verdes, mais `--filter=Nps` e `--filter=Desempenho` reconferidos contra a baseline herdada (não pode crescer)
