## (2) DECISÃO 2 — o SKU por VARIAÇÃO volta à linha

### A forma, MEDIDA no protótipo (e não inventada)

O protótipo não desenha o SKU na linha, mas desenha o SKU **duas vezes** em outros lugares, com a
**mesma** tipografia:

| onde | medida literal |
|---|---|
| `:178` (linha de grupo) | `<span style="font-family:'Geist Mono',monospace;font-size:11.5px">{{ g.sku }}</span> · Estoque N` |
| `:382` (painel de 460px) | `<span style="font-family:'Geist Mono',monospace;font-size:11.5px;color:#8A8A90">{{ sel.sku }}</span>` |

➡️ **O vocabulário do SKU neste protótipo é: Geist Mono, 11.5px, `#8A8A90`.** Em Tailwind deste
projeto: `font-pub-mono` + `text-[11.5px]` + `text-pub-txt-3` — e **a linha meta da célula
Publicação (`:212`) já é `text-[11.5px] text-pub-txt-3`**, exatamente como o MLB de `:213`, que
**não** redeclara o tamanho. ➡️ **O pedaço do SKU NÃO redeclara tamanho nem cor** (seria redundância
que o protótipo não tem) — só `font-pub-mono` no código e `flex-none`, espelhando `:213`.

O separador é o de `:218`: `<span style="color:#52525B;flex:none">·</span>` → `flex-none
text-pub-txt-off`.

### Onde entra

`resources/js/Components/Mlb/Publicador/publicacoes/CelulasDaLinha.jsx`, **ADITIVO**:

1. **Helper puro novo, exportado** — sem `.map(` (o gate do 180-08 proíbe `.map(` nos 3 arquivos) e
   sem `String(`:

```js
export function skuDaVariacao(skus) {
    if (!Array.isArray(skus)) return null;
    const lista = [];
    for (const bruto of skus) {
        if (typeof bruto !== 'string') continue;
        const limpo = bruto.trim();
        if (limpo === '' || lista.includes(limpo)) continue;
        lista.push(limpo);
    }
    if (lista.length === 0) return null;
    return { primeiro: lista[0], outros: lista.length - 1, lista };
}
```

2. **Dois nós no FIM da linha meta** de `CelulaPublicacao` (depois do nome do produto):

```jsx
{sku !== null && <span aria-hidden="true" className="flex-none text-pub-txt-off">·</span>}
{sku !== null && (
    <span title={tituloDoSku(sku)} className="flex-none">
        SKU <span className="font-pub-mono">{sku.primeiro}</span>{sku.outros > 0 ? ` +${sku.outros}` : ''}
    </span>
)}
```

### As decisões de forma, cada uma com motivo

| decisão | motivo |
|---|---|
| **no FIM da linha meta** | mantém `spans[1]`/`spans[2]`/`spans[3]` (título/meta/MLB) nos MESMOS índices absolutos do gate do 180-08 (`:1386`-`:1388`). ⚠️ A §12 do 180-08 e as asserções por índice são o motivo de não inserir no meio |
| **prefixo `SKU `** | divergência declarada de `:178`/`:382`, que mostram o código cru. Ali a coluna é inequívoca; aqui o código ficaria ao lado do MLB, e código nu sem rótulo é jargão — regra permanente do projeto. **E é o que o usuário já tinha** (`CelulaSku` de hoje escreve `SKU FON-001`) |
| **`+N` + `title` com a lista** | preserva byte a byte o contrato do `CelulaSku` de hoje (`N SKUs (um por variação): …`). "Melhorar sem regredir" |
| **`flex-none`** | espelha `:213` (o MLB). Quem encolhe é o nome do produto (`min-w-0 truncate`), não o SKU que o usuário pediu para ver |
| **aparece TAMBÉM na visão "Por produto"** | a linha de grupo mostra `produto_sku` (**do produto**); este é o da **VARIAÇÃO**. São dados diferentes; esconder um porque o outro existe seria mentir |
| **sem SKU → NADA desenhado** | "nunca medimos" ≠ "medimos e é zero". **Nem `—`, nem string vazia, nem separador solto.** ⚠️ O controller colapsa `null` em `[]` (`:740`); quem distingue é a prop `skuNaoColetado`, que já está na tela |
| **dedup** | a migration promete "DISTINTOS", mas `['A','A']` viraria `SKU A +1`, que seria falso. Dedup defensivo |
| **`CelulaSku` de `MeusAnuncios.jsx` NÃO é tocado** | segue **ÓRFÃO DECLARADO** e `publicador-meus-anuncios-sku-render.test.js` segue **verde sem reaponte**. ⚠️ **Asserção nova de que a página não o MONTA** — senão um plano futuro ligaria os dois e o SKU apareceria duas vezes |

### O que **NÃO** muda

`LinhaDeGrupoDeProduto.jsx` (`:317`, o SKU do produto), a busca por SKU (LIST-21), o controller, a
migration, `AcervoTriagemService`, `skuNaoColetado`.
