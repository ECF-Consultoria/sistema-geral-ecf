# ADR DATA-01 — Modelo N:N híbrido para multi-marketplace

## Contexto

Phase 18.5 introduziu `companies.marketplace` ENUM('meli','shopee','amazon')
como marketplace primário por empresa (default 'meli', backfill via
`dashboard:import-marketplace-from-csv`).

Phase 34/35 introduziu `companies.marketplaces_extras` JSON nullable para
marketplaces adicionais (semantic multi-marketplace do lado HubSpot).

Distribuição atual: 135 meli + 33 shopee + 1 amazon; 8 consumidores no
codebase leem `companies.marketplace` diretamente (AdmanService, providers
Sugador, comandos de diagnostico).

v13.0 precisa formalizar N:N pra Dashboard ECF agregado (Phase 58) sem
quebrar consumidores nem introduzir sobre-engenharia (Shopee/Amazon
ainda sao stubs sem integracao real nesta milestone).

## Decisao

Criar tabela pivot `company_marketplaces` com FK para companies, backfill
1 row primary por empresa a partir de `companies.marketplace`, MAS **manter**
as colunas legacy (`marketplace`, `marketplaces_extras`, `adman_account_id`,
`ml_store_id`, `adman_store_id`) em paralelo. Adicionar accessors no
`Company.php` que leem da pivot como fonte-de-verdade e escrevem em ambos
(pivot + coluna flat) via mutator, permitindo aos consumidores continuar
usando `$company->adman_account_id` sem refactor.

## Consequencias positivas

- Phase 58 tem estrutura N:N pronta pra query "empresa X mostra dados de N marketplaces"
- Zero blast radius nos 8 consumidores atuais
- Preparo pra Shopee/Amazon integracao real (v14+): adicionar row na pivot
- Rollback facil (drop pivot, colunas flat ficaram intactas)

## Consequencias negativas

- Debito tecnico consciente: schema com 2 fontes de verdade em paralelo
- Custo de +1 query por accessor call (mitigar com eager loading nas rotas criticas)
- Drop das colunas flat fica pra milestone futura (v14+) apos refactor de todos os consumidores

## Alternativas consideradas

- **N:N vazio + drop das flags**: over-engineering pra Shopee/Amazon stubs, risco alto de regressao em Sugadores/Dashboard.
- **So ADR sem migration**: nao habilita Phase 58 (dashboards multi-marketplace).
- **Manter modelo hibrido atual**: nao formaliza; Phase 58 teria que trabalhar com JSON o que gera queries complexas.

```php
<?php

namespace App\Console\Commands;

use App\Models\Company;
use App\Models\CompanyMarketplace;
use Illuminate\Console\Command;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

/**
 * Phase 57 v13.0 — Backfill idempotente da tabela pivot company_marketplaces.
 *
 * Para cada empresa:
 * 1. Cria/atualiza row PRIMARY a partir de companies.marketplace + adman_account_id + ml_store_id
 * 2. Cria/atualiza rows EXTRAS a partir de companies.marketplaces_extras (JSON array)
 *
 * Rerun eh safe — usa updateOrCreate na chave (company_id, marketplace).
 *
 * @see .planning/adrs/DATA-01-multi-marketplace-model.md
 */
class BackfillCompanyMarketplaces extends Command
{
    protected $signature = 'companies:backfill-marketplaces {--dry-run : Só mostra o que faria, sem gravar}';
    protected $description = 'Backfill idempotente da tabela pivot company_marketplaces a partir dos campos legacy';

    public function handle(): int
    {
        $dry = $this->option('dry-run');
        $total = Company::count();
        $this->info("[Phase57] Backfill company_marketplaces — {$total} empresas" . ($dry ? ' (DRY-RUN)' : ''));

        $stats = [
            'processed' => 0,
            'primary_created' => 0,
            'primary_updated' => 0,
            'extras_created' => 0,
            'extras_skipped' => 0,
            'errors' => 0,
        ];

        Company::query()->chunkById(200, function ($companies) use ($dry, &$stats) {
            foreach ($companies as $company) {
                try {
                    $this->processCompany($company, $dry, $stats);
                    $stats['processed']++;
                } catch (\Throwable $e) {
                    $stats['errors']++;
                    Log::error("[Phase57] backfill falhou empresa {$company->id}: " . $e->getMessage());
                }
            }
        });

        $this->info('');
        $this->info("[Phase57] Concluído:");
        $this->table(['Métrica', 'Valor'], collect($stats)->map(fn($v, $k) => [$k, $v])->values()->toArray());

        return self::SUCCESS;
    }

    private function processCompany(Company $company, bool $dry, array &$stats): void
    {
        // 1. Row primary — a partir de companies.marketplace
        $primaryMp = $company->attributes['marketplace'] ?? 'meli';
        $primaryData = [
            'store_id' => $company->attributes['ml_store_id'] ?? null,
            'adman_id' => $company->attributes['adman_account_id'] ?? null,
            'is_primary' => true,
            'active' => true,
            'integracao_status' => 'ativa',
        ];

        $existing = $dry ? null : CompanyMarketplace::where('company_id', $company->id)
            ->where('marketplace', $primaryMp)
            ->first();

        if (!$dry) {
            CompanyMarketplace::updateOrCreate(
                ['company_id' => $company->id, 'marketplace' => $primaryMp],
                $primaryData
            );
        }

        if ($existing) {
            $stats['primary_updated']++;
        } else {
            $stats['primary_created']++;
        }

        // 2. Rows extras — a partir de companies.marketplaces_extras JSON
        $extras = $company->attributes['marketplaces_extras'] ?? null;
        if (is_string($extras)) {
            $extras = json_decode($extras, true) ?: [];
        }

        if (!is_array($extras) || empty($extras)) {
            return;
        }

        foreach ($extras as $slug) {
            if (!is_string($slug) || $slug === $primaryMp) {
                $stats['extras_skipped']++;
                continue;
            }

            if (!in_array($slug, ['meli', 'shopee', 'amazon', 'magalu'], true)) {
                $stats['extras_skipped']++;
                Log::warning("[Phase57] marketplace_extras invalido '{$slug}' na empresa {$company->id}");
                continue;
            }

            if (!$dry) {
                CompanyMarketplace::updateOrCreate(
                    ['company_id' => $company->id, 'marketplace' => $slug],
                    ['is_primary' => false, 'active' => true, 'integracao_status' => 'pendente']
                );
            }
            $stats['extras_created']++;
        }
    }
}
```

**Notas críticas:**
- Uso `$company->attributes['marketplace']` (não `$company->marketplace`) para ler o RAW da coluna e evitar recursão infinita com accessors quando `marketplaces` relacionamento é lazy-loaded.
- Uso `$company->attributes['ml_store_id']` idem para não invocar o accessor da Task 4 (que consulta a pivot que ainda não existe no backfill).
- `chunkById(200)` para não estourar memória em 169+ empresas.
- `updateOrCreate` garante idempotência: rerun não duplica.

<?php

namespace Tests\Feature\Phase57;

use App\Models\Company;
use App\Models\CompanyMarketplace;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Illuminate\Support\Facades\Artisan;
use Tests\TestCase;

class BackfillMarketplacesTest extends TestCase
{
    use RefreshDatabase;

    /** @test */
    public function backfill_cria_row_primary_para_cada_empresa(): void
    {
        Company::factory()->count(3)->create();

        Artisan::call('companies:backfill-marketplaces');

        $this->assertSame(3, CompanyMarketplace::where('is_primary', true)->count());
    }

    /** @test */
    public function backfill_e_idempotente(): void
    {
        Company::factory()->count(2)->create();

        Artisan::call('companies:backfill-marketplaces');
        Artisan::call('companies:backfill-marketplaces');
        Artisan::call('companies:backfill-marketplaces');

        // Ainda so 2 rows primary (nao duplicou)
        $this->assertSame(2, CompanyMarketplace::where('is_primary', true)->count());
    }

    /** @test */
    public function backfill_processa_marketplaces_extras_como_rows_extras(): void
    {
        $company = Company::factory()->create([
            'marketplace' => 'meli',
            'marketplaces_extras' => ['shopee', 'amazon'],
        ]);

        Artisan::call('companies:backfill-marketplaces');

        $this->assertSame(1, CompanyMarketplace::where('company_id', $company->id)->where('is_primary', true)->count());
        $this->assertSame(2, CompanyMarketplace::where('company_id', $company->id)->where('is_primary', false)->count());
        $marketplaces = CompanyMarketplace::where('company_id', $company->id)->pluck('marketplace')->sort()->values()->toArray();
        $this->assertSame(['amazon', 'meli', 'shopee'], $marketplaces);
    }

    /** @test */
    public function backfill_skipa_marketplaces_extras_invalido_e_loga(): void
    {
        \Illuminate\Support\Facades\Log::spy();

        Company::factory()->create([
            'marketplace' => 'meli',
            'marketplaces_extras' => ['tiktok', 'invalido'],  // slugs não permitidos
        ]);

        Artisan::call('companies:backfill-marketplaces');

        // So a row primary, sem os extras invalidos
        $this->assertSame(1, CompanyMarketplace::count());

        \Illuminate\Support\Facades\Log::shouldHaveReceived('warning')->atLeast()->once();
    }

    /** @test */
    public function dry_run_nao_grava(): void
    {
        Company::factory()->count(2)->create();

        Artisan::call('companies:backfill-marketplaces', ['--dry-run' => true]);

        $this->assertSame(0, CompanyMarketplace::count());
    }
}
