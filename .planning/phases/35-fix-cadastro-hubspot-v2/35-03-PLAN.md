# Plan 35-03: Notificação Comercial quando empresa via HubSpot tem pendências

Wave 2. Paralelo com 35-02. Sem conflito: 35-02 mexe em criarEmpresa parte do mapping; 35-03 adiciona dispatch da notification APÓS o commit. Eventual conflito de merge no controller será trivial (linhas distintas do método).

## Escopo

1. **`App\Notifications\EmpresaHubspotPendenteNotification`**:
   ```php
   namespace App\Notifications;
   use App\Models\Company;
   class EmpresaHubspotPendenteNotification extends BaseNotification {
       public function __construct(private Company $company, private array $pendencias) {}

       protected function buildTitle(): string {
           return "Empresa nova via HubSpot com pendências: {$this->company->name}";
       }
       protected function buildBody(): string {
           $labels = [
               'sem_responsavel'       => 'sem responsável',
               'sem_cust_id'           => 'sem cust ID',
               'sem_email_colaborador' => 'sem email colaborador',
               'sem_servico'           => 'sem serviço',
           ];
           $humanizadas = collect($this->pendencias)
               ->map(fn($p) => $labels[$p] ?? $p)
               ->implode(', ');
           return "Pendências: {$humanizadas}";
       }
       protected function buildLink(): ?string {
           return route('companies.show', $this->company->id);
       }
       protected function buildData(): array {
           return [
               'company_id'  => $this->company->id,
               'pendencias'  => $this->pendencias,
               'fonte'       => 'hubspot',
           ];
       }
   }
   ```
   (Adaptar conforme assinatura real de BaseNotification — ler primeiro.)

2. **`App\Support\AudienciaComercial`**:
   ```php
   namespace App\Support;
   use App\Models\User;
   use Illuminate\Support\Collection;
   use Illuminate\Support\Facades\DB;
   class AudienciaComercial {
       public static function lideresEPermissionados(): Collection {
           // Líderes do setor Comercial
           $lideresIds = DB::table('user_setores as us')
               ->join('setores as s', 's.id', '=', 'us.setor_id')
               ->join('cargos as c', 'c.id', '=', 'us.cargo_id')
               ->where('s.slug', 'comercial')
               ->where('c.slug', 'like', '%lider%')
               ->pluck('us.user_id');

           // Cargo direto lider-comercial
           $cargoDireto = DB::table('user_setores as us')
               ->join('cargos as c', 'c.id', '=', 'us.cargo_id')
               ->where('c.slug', 'lider-comercial')
               ->pluck('us.user_id');

           // Users com permission comercial.cadastrar_empresa
           // (helper hasPermission do User — buscar todos via permission_roles ou similar; depende da impl atual)
           $permissionados = User::query()
               ->where('active', true)
               ->get()
               ->filter(fn($u) => $u->hasPermission('comercial.cadastrar_empresa'))
               ->pluck('id');

           $todos = $lideresIds->concat($cargoDireto)->concat($permissionados)->unique()->values();

           return User::whereIn('id', $todos)->where('active', true)->get();
       }
   }
   ```
   (Adaptar conforme schema real — verificar como `hasPermission` funciona e como user→setor→cargo está conectado.)
