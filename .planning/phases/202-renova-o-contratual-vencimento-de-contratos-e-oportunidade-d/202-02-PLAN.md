Formas REAIS da API (usar nos fakes):
- POST /crm/v3/objects/deals → 201 `{"id":"123","properties":{...},"createdAt":"...","archived":false}`; corpo de envio `{"properties":{...},"associations":[{"to":{"id":"<companyId>"},"types":[{"associationCategory":"HUBSPOT_DEFINED","associationTypeId":5}]},{"to":{"id":"<contactId>"},"types":[{"associationCategory":"HUBSPOT_DEFINED","associationTypeId":3}]}]}` (5 = deal→company, 3 = deal→contact).
- POST /crm/v3/objects/deals/search → `{"total":1,"results":[{"id":"123","properties":{"pipeline":"958410144","dealstage":"1480135340","ecf_renovacao_chave":"..."},"archived":false}]}`; corpo `{"filterGroups":[{"filters":[{"propertyName":"ecf_renovacao_chave","operator":"EQ","value":"..."}]}],"properties":[...],"limit":10}`.
- GET /crm/v3/objects/deals/{id} → 404 quando apagado/arquivado.
- GET /crm/v3/pipelines/deals/{pipelineId} → `{"id":"958410144","label":"Renovações contrato","stages":[{"id":"1480135340","label":"Proximo do termino de contrato","metadata":{"isClosed":"false"}}, ...]}`.
- GET /crm/v3/properties/deals/{name} → 404 se não existe; POST /crm/v3/properties/deals cria (`name,label,type:"string",fieldType:"text",groupName:"dealinformation",hasUniqueValue`).
- PUT /crm/v4/objects/deals/{dealId}/associations/default/{companies|contacts}/{toId} → associação padrão idempotente.
