`app/Support/Clicksign/ClicksignHmacVarredura.php` (classe nova, estática, sem I/O):

- `public const CANDIDATAS` — mapa `chave => descrição` das 4 fórmulas, nesta ordem exata:
  - `soma_body_secret`       → `hash('sha256', $rawBody . $secret)`
  - `soma_secret_body`       → `hash('sha256', $secret . $rawBody)`
  - `hmac_body_chave_secret` → `hash_hmac('sha256', $rawBody, $secret)`
  - `hmac_secret_chave_body` → `hash_hmac('sha256', $secret, $rawBody)`
- `public const FORMULA_CONFIRMADA = null;` — **fica `null` neste plano**; só o plano 129-02
  (depois da medição real) troca por uma das 4 chaves acima.
- `public const PREFIXO = 'sha256=';` — o header `Content-Hmac` vem como `sha256=<hex>`
  (convergente em todas as fontes; hex confirmado, base64 descartado — `129-RESEARCH.md` §2).
- `public static function calcular(string $rawBody, string $secret, string $formula): string`
  — devolve `'sha256=' . <hex>` para UMA candidata; lança `\InvalidArgumentException` se a chave
  não existir em `CANDIDATAS`.
- `public static function calcularTodas(string $rawBody, string $secret): array`
  — `['soma_body_secret' => 'sha256=...', ...]`, as 4.
- `public static function identificarTodas(string $rawBody, string $secret, string $headerRecebido): array`
  — `['soma_body_secret' => bool, ...]`, comparação por `hash_equals()` (NUNCA `===`).
- `public static function vencedora(string $rawBody, string $secret, string $headerRecebido): ?string`
  — chave da primeira candidata que bate, ou `null`.
- `public static function confere(string $rawBody, string $secret, string $headerRecebido): bool`
  — usa `FORMULA_CONFIRMADA`; **lança `\RuntimeException` com a mensagem
  `'Gate A1 não fechado: a fórmula do Content-Hmac ainda não foi medida contra webhook real.'`
  enquanto a constante for `null`.** É esta exceção que impede o receiver de produção
