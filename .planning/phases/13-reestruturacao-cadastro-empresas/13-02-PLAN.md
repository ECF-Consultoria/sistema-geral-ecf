<objective>
Permissions, setor Comercial e migração retroativa: adicionar 'comercial.cadastrar_empresa' ao catálogo de permissões, criar o setor "Comercial" via migration de dados (idempotente), e migrar retroativamente todos os mlb_empresas sem company_id para ter um registro correspondente em companies com company_id preenchido.

Purpose: Sem a permission_key no catálogo, o middleware 'permission:comercial.cadastrar_empresa' não saberia o que conceder. Sem o setor Comercial no banco, não é possível adicionar membros via /sistema/setores. Sem a migration retroativa, mlb_empresas ficariam desvinculadas de companies e a query de fechamento não as enxergaria.

Output: Permissions.php atualizado, migration de dados idempotente pronta para executar, companies retroativas criadas.
</objective>
