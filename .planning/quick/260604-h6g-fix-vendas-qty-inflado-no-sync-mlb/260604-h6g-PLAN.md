# Quick Task 260604-h6g: Corrigir vendas_qty inflado no sync de vendas MLB

## Contexto / Causa raiz (confirmada em produção)

Anúncios mostravam quantidades impossíveis (ex.: MLB5826796048 / "By Mobile" / Kaio →
109 un. em 03/06, anúncio `closed` com 0 vendas na janela atual).

Evidência prod: BD id 1090 → `vendas_qty=109`, `net_billing=57640.29`. API agora
(01–04/06) → `soldQuantity.value=0`, `status=closed`. Logo o 109 é resíduo de sync antigo.

Três fatores combinados:
1. `vendas_qty = soldQuantity.value` da **janela** do sync; modal permitia janelas largas
   (ano/histórico) → valor cumulativo de meses/anos carimbado numa publicação.
2. `GREATEST(COALESCE(vendas_qty,0), {qty})` → valor **só cresce, nunca corrige pra baixo**.
3. Match **global por mlb_code** sem escopo de empresa/período; e `extrairMlbsVendidos`
   pula `qty<=0` → anúncios sem venda nunca são zerados.

## Decisão (aprovada)

Tirar GREATEST + escopo por cust_id + travar janela ao mês + reset-antes-de-aplicar +
re-sync do mês pra normalizar resíduos.

## Tarefas

### Tarefa 1 — Service único de gravação (`VendasSyncService`)
- **Arquivo (novo):** `app/Services/VendasSyncService.php`
- `syncEmpresa(custId, from, to, userId=null)`: fetch + extract + **reset do escopo**
  (cust_id + data na janela [+ user_id]) + **apply com valor exato** (sem GREATEST),
  tudo em transação. `extrairMlbsVendidos` com `max` (não soma).
- **Done:** regra de gravação única e correta.

### Tarefa 2 — Delegar os 4 caminhos ao service
- `MlbController::syncVendasPublicador` (escopo user_id), `::syncVendasAdman`,
  `SyncTodasVendasAdmanJob::handle`, comando `mlb:sync-vendas`.
- Remover GREATEST e as cópias duplicadas de `extrairMlbsVendidos` (Job + comando).
- Alinhar throttle do comando (já 7s em prod) e lógica de extração (max).
- **Done:** nenhum caminho usa GREATEST nem match global.

### Tarefa 3 — Travar a janela do sync ao mês (UI)
- `resources/js/Pages/Mlb/Vendas.jsx` (`SyncModal`): remover atalhos ano/histórico e
  date pickers livres; sincroniza sempre o **mês exibido** (`mesRef`).
- **Done:** impossível disparar sync com janela larga pela UI.

### Tarefa 4 — Build + deploy + re-sync corretivo
- `npm run build`; deploy git-integrado (fast-forward em origin/main + deploy.sh).
- Em prod: `php artisan mlb:sync-vendas` (mês atual) pra normalizar resíduos; validar
  MLB5826796048 (esperado: vendas_qty=0, vendido=false).
