# Quick Task 260601-fm3 — KPIs Adman via API do Mercado Livre

## Objetivo

No painel de empresas (`Companies/Show`), fazer as empresas **ML-only** (sem
`adman_account_id`, com token ML) exibirem o **mesmo conjunto de KPIs
financeiros da Adman** — Faturamento, ACOS, TACOS e Margem % — porém calculados
exclusivamente a partir dos dados da API do Mercado Livre já gravados em
`adman_metrics` (via sync direto ML).

Hoje o ramo ML-only mostra apenas Faturamento / Ad Spend / TACOS (3 cards),
divergindo do que os usuários viam na Adman.

## Decisões travadas (não revisitar)

- **Margem %**: a API do ML não fornece CMV (custo do produto) nem impostos,
  necessários para a margem de contribuição da Adman. Mantém `null` → UI exibe
  "—" com tooltip "Requer CMV — indisponível na API do Mercado Livre". **Não**
  criar cadastro de CMV nesta task.
- **Arquitetura**: agregar no backend (`CompanyController::show`), unificando o
  ramo ML com a grade de 4 KPIs do Adman. **Sem migração** — o `ad_revenue`
  histórico já está em `raw_data.ads` de cada linha de `adman_metrics`.

## Mapeamento de KPIs (Adman → ML)

| KPI | Fórmula | Fonte ML |
|-----|---------|----------|
| Faturamento (30d) | Σ revenue | `adman_metrics.revenue` (pedidos pagos) |
| TACOS (30d) | Σ ad_spend ÷ Σ revenue × 100 | `ad_spend` + `revenue` |
| ACOS (30d) | Σ ad_spend ÷ Σ ad_revenue × 100 | `ad_spend` + `raw_data.ads.ad_revenue` |
| Margem % (30d) | — (N/D) | indisponível na API ML (precisa CMV/impostos) |
| Invest. Ads (30d) | Σ ad_spend | `ad_spend` |

ACOS/TACOS são **recomputados sobre as somas do período** (não média dos
diários), garantindo consistência com a definição da Adman.

## Tarefas

### Tarefa 1 — Backend: agregação ML-only no controller
- **Arquivo:** `app/Http/Controllers/CompanyController.php`
- **Ação:** no `show()`, substituir o ramo vazio
  `elseif (! $company->adman_account_id && $company->mlToken)` por agregação dos
  últimos 30 dias de `$company->admanMetrics`, populando `$revenue30d`,
  `$acos30d`, `$tacos30d`, `$margin30d` (null) e `$adInvestment30d`.
- **Verificar:** `php -l` sem erros; props `acos_30d`/`tacos_30d`/`ad_investment_30d`
  passam a vir preenchidas para empresa ML-only.
- **Done:** ramo ML-only computa as somas e expõe os 5 valores nas props.

### Tarefa 2 — Frontend: grade unificada de 4 KPIs
- **Arquivo:** `resources/js/Pages/Companies/Show.jsx`
- **Ação:** remover `kpi30`; renderizar SEMPRE a grade de 4 cards
  (Faturamento/ACOS/TACOS/Margem % 30d) lendo `company.*_30d`. No card Margem %,
  quando `null` e `isMlOnly`, exibir ícone `Info` + tooltip. Importar `Info` de
  `lucide-react`. Linha operacional (NPS/Absenteísmo/Invest. Ads) inalterada.
- **Verificar:** `npm run build` sem erros.
- **Done:** empresa ML-only mostra os 4 KPIs + linha operacional; Adman inalterado.
