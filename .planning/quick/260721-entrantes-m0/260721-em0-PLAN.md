# Quick 260721-em0: Aba "Entrantes (M0)" no Painel Polos

## Objetivo
Nova sub-aba **"Entrantes (M0)"** dentro da lente **Metas** do Painel Polos,
espelhando o layout do PDF "MAPEAMENTO POLOS - Entrantes", com dados do **sistema**
(prop `empresas`), escopados à **Fase M0**. Só frontend — nenhum campo novo no backend
(todos já chegam em `empresas`: `cust_id`, `acesso_colaborador`, `grupo_whatsapp`,
`polo`, `fase`, `status_entrada`).

## Definições (confirmadas com dados de prod)
- **Meta M0** = `Cust ID` **E** `Acesso Colaborador` ('Com acesso'). Grupo omitido do
  checklist (é true em ~99% — não filtra nada; a planilha também só cobra os 2).
- **Aceites no Projeto** = funil do `status_entrada` (em contato · Reserva prox mês ·
  Não tem CNPJ · Não tem conta ML · Não responde). "Feito" = já entrou (fora do funil).
- **Escopo** = `fase === 'M0'` (coorte de entrada). M1+/Churn/Encerrado ficam de fora.

## Layout (espelha o PDF)
1. **Meta M0 — [mês]**: hero `cust+acesso / total M0` (%) + cards por polo
   (cust+acesso / total do polo · "Com cust" N · %).
2. **Checklist M0**: Cust ID N/total · Acesso Colaborador N/total (barras).
3. **Aceites no Projeto**: contador + gráfico de barras "Status da Entrada".

## Tarefas
1. `resources/js/Pages/Polos/components/EntrantesM0Panel.jsx` (novo) — computa e renderiza.
2. `resources/js/Pages/Polos/Painel.jsx` — import + sub-toggle na lente Metas
   ("Entrantes (M0)" | "Torre de Comando"), default Entrantes.
3. `npm run build`.
