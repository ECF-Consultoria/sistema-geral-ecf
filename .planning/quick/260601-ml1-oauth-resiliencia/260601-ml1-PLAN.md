# Quick Task 260601-ml1 — Resiliência OAuth Mercado Livre

Diagnóstico + correção de 4 problemas reportados na integração OAuth do ML.

## Problema 1 — Revogação indevida (BUG crítico)

**Causa-raiz:** `MercadoLivreService::refreshToken()` marca `status='revoked'`
em QUALQUER resposta não-2xx. Erros transitórios (5xx, 429, timeout, falha de
rede) revogam permanentemente. Após revogado, `ensureValidToken()` retorna null
para sempre e `RefreshMlTokens` só busca `active` → nunca recupera.

**Secundário:** refresh token do ML é single-use (rotaciona). Sem lock, cron das
08:00 + sync manual podem usar o mesmo refresh_token → `invalid_grant` → revoga.

**Correção:**
- `refreshToken()`: revogar SÓ em `invalid_grant`. Transitórios mantêm `active`
  e lançam exceção retentável. `ConnectionException` (rede) não revoga.
- Serializar com `Cache::lock("ml-refresh-{companyId}")`; recarregar token do
  banco após o lock; pular refresh se já renovado há <30s e não expira em <5min.
- Reativar (`status=active`) quando um refresh de token revogado dá certo.
- `RefreshMlTokens`: incluir revogados recentes (≤7d) para auto-recuperação;
  flag `--recover` força retry de todos os revogados.

## Problema 2 — Display de expiração

`expires_at` é a expiração do ACCESS token (6h) — "Expira em 22:58" assusta.
**Correção:** status "Conexão ativa" em destaque; detalhes técnicos discretos;
`Expira em` → `Próxima renovação do token` (Companies/Show + MlOAuth/Index).

## Problema 3 — Consentimento OAuth

A auth URL está correta (auth.mercadolivre.com.br/authorization + PKCE S256).
Confirmado: o ML pula a tela de consentimento para contas que JÁ autorizaram o
app — comportamento padrão. **Sem mudança de código**; adicionar nota explicativa
no modal do link.

## Problema 4 — Inconsistência de IDs

`ml_user_id` do token é o Seller ID autoritativo (= Cust ID). Callback só
preenchia `ml_store_id` se vazio (não corrigia divergência).
**Correção:** callback sobrescreve `ml_store_id = ml_user_id` (Spatie audita a
mudança) + log. UI mostra um único "Cust ID (Seller ID ML)" e oculta os campos
Adman legados quando vazios. Atualizar a tela de resultado do OAuth.
