# Quick Task 260610-f69 — Dashboard Admin: filtros + widget carteira

## Contexto

### Bug 1 — Filtro "Analistas" mistura Estrategistas

[Admin.jsx:144](resources/js/Pages/Dashboard/Admin.jsx#L144):
```jsx
const consultores = (users || []).filter(u => u.role === 'consultor');
```

Mas Nathalia/Rubens/Débora/Douglas têm `users.role = consultor` no banco mesmo sendo
**cargo Estrategista** (setor Performance). Caem no select de Analistas indevidamente.

### Bug 2 — Filtro "Estrategistas" só mostra Luiz

[Admin.jsx:145](resources/js/Pages/Dashboard/Admin.jsx#L145):
```jsx
const mentores = (users || []).filter(u => u.role === 'mentor');
```

Só Luiz Henrique tem `role=mentor`. Os outros 4 estrategistas reais (Nathalia, Rubens,
Débora, Douglas) têm `role=consultor` no banco.

### Bug 3 — Sem cross-filter

Não existe lógica que conecte os dois selects. Selecionar Stefani não restringe
estrategistas aos que trabalham com ela.

### Bug 4 — Widget "Carteira Portfólio por Profissional" incompleto + TACOS zerado

[DashboardController.php:418-446](app/Http/Controllers/DashboardController.php#L418-L446):
```php
$userPortfolios = $users->map(function ($u) use ($metrics, $companies, $revenueByCompany) {
    $uCompanies = $companies->filter(function ($c) use ($u) {
        return $u->isMentor()
            ? $c->estrategista->contains('id', $u->id)
            : $c->consultor->contains('id', $u->id);
    });
    if ($uCompanies->isEmpty()) return null;
    ...
    'avg_tacos' => $uMetrics->count() > 0 ? round($uMetrics->avg('tacos'), 2) : null,
```

Problemas:
1. `$companies` é a lista FILTRADA → quando user filtra por uma empresa, carteira dos
   outros some.
2. `$u->isMentor()` checa `role === 'mentor'` → só Luiz cai no branch estrategista;
   Nathalia/Rubens/Débora/Douglas caem no branch consultor errado (busca em
   `$c->consultor` em vez de `$c->estrategista`) e quase nunca acham nada → carteira vazia.
3. `avg('tacos')` calcula média sobre todas as métricas diárias da carteira. Empresas sem
   ads ativo têm `tacos=0` em todos os dias, diluindo o avg. Fica próximo de zero.

### Regra correta

A fonte da verdade pra "É Analista" vs "É Estrategista" é o **cargo no setor Performance**
via pivot `user_setores.cargo_id` → `cargos.slug` ∈ {`analista`, `estrategista`}.
O campo `users.role` é legacy (admin/consultor/mentor) e não reflete a taxonomia atual.

Onde hoje está:

Manter `$users` (continua sendo usado pelo `buildRanking` na linha 416 — não mudar essa

```php
// Fonte da verdade: cargo no setor Performance (user_setores.cargo_id → cargos.slug)
$analistas = User::where('active', true)
    ->whereHas('setores', function ($q) {
        $q->where('setores.slug', 'performance')
          ->whereHas('cargos', fn($q2) => $q2->where('slug', 'analista'));
    })
    ->orderBy('name')
    ->get(['id', 'name']);

$estrategistas = User::where('active', true)
    ->whereHas('setores', function ($q) {
        $q->where('setores.slug', 'performance')
          ->whereHas('cargos', fn($q2) => $q2->where('slug', 'estrategista'));
    })
    ->orderBy('name')
    ->get(['id', 'name']);
```

**ATENÇÃO ao relacionamento**: o `whereHas` aninhado em `cargos` precisa baterem corretamente.
O executor deve verificar a definição do relacionamento `User::setores()` e a definição
de `cargos.setor_id` antes de finalizar. Se a query `whereHas('setores'...whereHas('cargos'...))`
não conseguir filtrar pelo `cargo_id` do PIVOT `user_setores` (que é o que importa, não
qualquer cargo do setor), trocar para uma query direta no pivot:

```php
$analistas = User::where('active', true)
    ->whereExists(function ($q) {
        $q->from('user_setores as us')
          ->join('cargos as c', 'c.id', '=', 'us.cargo_id')
          ->whereColumn('us.user_id', 'users.id')
          ->where('c.slug', 'analista');
    })
    ->orderBy('name')
    ->get(['id', 'name']);
```

(Análogo para `estrategistas`.) O executor deve testar via tinker antes do commit final
qual abordagem retorna o conjunto certo. Critério: `$analistas` deve incluir Ana Julia,
Danilo, Gabriela, Gustavo, Maycon Gomes, Stefani. `$estrategistas` deve incluir Débora Lima,
Douglas, Luiz Henrique, Nathalia Martins, Rubens.

**A.2 — Construir `$combinacoes` (pares analista↔estrategista que coabitam empresas).**

```php
$combinacoes = DB::table('company_users as cu_a')
    ->join('company_users as cu_e', function ($j) {
        $j->on('cu_e.company_id', '=', 'cu_a.company_id')
          ->where('cu_e.role', '=', 'estrategista');
    })
    ->where('cu_a.role', '=', 'consultor')
    ->select('cu_a.user_id as analista_id', 'cu_e.user_id as estrategista_id')
    ->distinct()
    ->get();
```

**A.3 — Refazer `$userPortfolios`** (substitui linhas 418-446):

```php
// Carteira por profissional: TODOS analistas + estrategistas, usando suas próprias
// carteiras (independente do filtro principal — o widget é uma visão completa).
$todosProfissionais = $analistas->map(fn($u) => ['user' => $u, 'tipo' => 'analista'])
    ->concat($estrategistas->map(fn($u) => ['user' => $u, 'tipo' => 'estrategista']));

$userPortfolios = $todosProfissionais->map(function ($item) use ($since) {
    $u = $item['user'];
    $tipo = $item['tipo'];

    // Empresas da carteira via pivot company_users (não filtra por $companies)
    $companyIds = ($tipo === 'estrategista')
        ? $u->estrategistaCompanies()->where('active', true)->pluck('companies.id')
        : $u->consultorCompanies()->where('active', true)->pluck('companies.id');

    if ($companyIds->isEmpty()) return null;

    // Métricas do período pra essas empresas
    $uMetrics = AdmanMetric::whereIn('company_id', $companyIds)
        ->where('reference_date', '>=', $since->toDateString())
        ->get();

    // TACOS correto: SUM(ad_spend) / SUM(revenue) * 100. Null se revenue = 0.
    $totalRevenue = (float) $uMetrics->sum('revenue');
    $totalAdSpend = (float) $uMetrics->sum('ad_spend');
    $tacosCarteira = $totalRevenue > 0
        ? round(($totalAdSpend / $totalRevenue) * 100, 2)
        : null;

    return [
        'id'              => $u->id,
        'name'            => $u->name,
        'tipo'            => $tipo,              // 'analista' | 'estrategista'
        'role'            => $u->role,           // legacy back-compat
        'companies_count' => $companyIds->count(),
        'avg_tacos'       => $tacosCarteira,     // agora é o TACOS REAL da carteira
        'total_revenue'   => $totalRevenue,
        'avg_margin'      => $uMetrics->count() > 0 ? round($uMetrics->avg('contribution_margin_pct'), 2) : null,
        'total_ad_spend'  => $totalAdSpend,
    ];
})->filter()->sortBy('name')->values();
```
