# Quick Task 260609-j3m — Fix errors source em Mlb/Treinamentos.jsx

## Contexto

Bug idêntico ao corrigido no quick 260609-gr4 (`resources/js/Pages/Users/Index.jsx`).
Foi pré-identificado no audit estruturado daquela task como o ÚNICO outro arquivo
com o mesmo antipadrão (13 arquivos triados na interseção, 12 falso positivo,
1 bug confirmado = este).

### Localização do bug

Arquivo: `resources/js/Pages/Mlb/Treinamentos.jsx`

- **Linha 18:** `const { data, setData, processing, reset, errors } = useForm({ ... })`
  → `errors` destructurado do useForm
- **Linha 40:** `router.put(route('mlb.treinamentos.update', ...), data, ...)`
  → submit via router global (não atualiza errors do useForm)
- **Linha 42:** `router.post(route('mlb.treinamentos.store'), data, ...)`
  → mesma coisa
- **Linha 225:** `{errors.titulo && <p>...{errors.titulo}</p>}` — render que nunca dispara
- **Linha 245:** `{errors.url_video && <p>...{errors.url_video}</p>}` — idem

Consequência: backend rejeita validação de `titulo` ou `url_video` → 302 com errors →
Inertia injeta em `usePage().props.errors` shared prop → componente lê de `useForm.errors`
que é `{}` → mensagens nunca renderizam → modal fica preso sem feedback.

### Segundo form da página (NÃO MEXER)

Linha 22: `const configForm = useForm({ link_acesso: linkAcesso ?? '' })`.
Linha 48: `configForm.post(route('mlb.config'), ...)` — usa o `.post()` do próprio form.
Como o submit é via o form, o `configForm.errors` interno funciona normalmente.
Não está sendo lido na render hoje, mas se for adicionado no futuro funciona.
**Manter exatamente como está.**

## Tarefa única

### T-01 — Trocar fonte de `errors` no form de treinamento

Arquivo: `resources/js/Pages/Mlb/Treinamentos.jsx`

**Mudança 1 — import (linha 8):**

```diff
- import { router, useForm } from '@inertiajs/react';
+ import { router, useForm, usePage } from '@inertiajs/react';
```

**Mudança 2 — fonte do `errors` (linha 18):**

```diff
- const { data, setData, processing, reset, errors } = useForm({
+ const { data, setData, processing, reset } = useForm({
      titulo: '', descricao: '', url_video: '', ordem: 0, ativo: true,
  });
+ // errors vem da shared prop do Inertia (não do useForm) porque o submit
+ // do form de treinamento abaixo usa router.put/router.post (global).
+ // useForm.errors só popula quando o próprio form submete via form.post/put.
+ const { errors } = usePage().props;
```

**Não alterar:** `configForm` (linha 22), `submitConfig` (linha 46-49), nada na renderização.
