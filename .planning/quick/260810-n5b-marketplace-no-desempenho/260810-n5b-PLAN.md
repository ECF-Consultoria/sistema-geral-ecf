# Quick 260810-n5b — Marketplace no Desempenho

Item 3 da seção **Desempenho** do PDF "Demandas e Fluxos – Sistema ECF"
(Maycon): *"Incluir no Desempenho a informação de qual marketplace pertence a
conta"*. Perguntado onde, ele escolheu **tabela por empresa** e **card do
profissional**.

## De onde vem o marketplace (a decisão que importa)

O caminho aparentemente óbvio — `companies.marketplace` — **não serve**, e isso
foi medido, não suposto:

```
companies.marketplace  → {"meli": 171}   (171 de 171, nenhuma outra)
company_marketplaces   → 0 linhas
```

`companies.marketplace` é o marketplace da conta **Adman**, usado para montar a
URL da API (`/{marketplace}/accounts/...`), com default `'meli'`. Nunca foi
populado com Shopee, e a pivot `company_marketplaces` (Fase 57) está vazia.
Usar esse campo diria "Mercado Livre" para toda loja Shopee.

A fonte correta já está na tela, escrita como jargão: `fonte_financeira`,
derivada do **serviço contratado** em
`CarteiraContextService::flagsFinanceirasPorSetor()`:

| setor do vínculo | fonte_financeira | marketplace |
|---|---|---|
| `performance` | `adman` | Mercado Livre |
| `shopee` | `shopee` | Shopee |
| polos / publicação / outros | `null` | sem fonte financeira |

É também o dado *certo* para esta tela: é o marketplace de cuja métrica saiu a
pontuação daquela loja.

**Nuance registrada:** empresa com os DOIS vínculos elegíveis resolve `adman`
(regra de desempate do `CompanyScoreService`), então a linha mostra Mercado
Livre. É o marketplace que produziu os números da linha — não uma omissão.

## Por que 100% front

`fonte_financeira` já está no payload ao vivo **e** na coluna do snapshot
congelado (`CompanyScoreSnapshotWriter`), então traduzir no front funciona
igual em mês corrente e em competência fechada.

Um campo `marketplaces` novo exigiria **migration** no
`desempenho_company_score_snapshots` (o writer grava colunas fixas, não JSON) e
não estaria nas competências já congeladas. Custo alto para informação que já
está lá.

Sem backend ⇒ **sem bump de cache**: nenhum cálculo muda.
