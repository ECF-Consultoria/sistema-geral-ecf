    Mecânica de escala (área ∝ valor):
    - `maxFat = Math.max(...itens.map(i => i.faturamento || 0), 0)`.
    - Para cada item: `scale = maxFat > 0 ? Math.sqrt((i.faturamento || 0) / maxFat) : 0`
      (sqrt para a ÁREA crescer proporcional ao faturamento). Aplicar piso visual
      `scaleVis = Math.max(scale, 0.18)` para cidades muito pequenas não sumirem
      (mas a maior fica com scale=1). Documentar o piso em comentário pt-BR.

    Render por item (cada cidade é uma coluna flex, alinhada pela BASE):
    - Resolver `const shape = shapeForPolo(i.polo)` (importar de `./cityShapes`).
    - SE shape existe: desenhar um `<svg>` cuja LARGURA/ALTURA renderizadas escalam por
      `scaleVis`. Como as cidades têm w/h diferentes, normalize a ALTURA: a altura px
      do svg = `maxHeight * scaleVis * (shape.h / maxShapeH)` onde
      `maxShapeH = Math.max(...shapes.h)` entre os itens com contorno — assim cidades
      "mais altas" no contorno não dominam; o objetivo é a área visual refletir o valor.
      Alternativa aceitável e mais simples: fixar a altura px = `maxHeight * scaleVis` e
      deixar a largura seguir o aspect-ratio do viewBox (`width:auto`). Escolha a opção
      simples (altura = maxHeight*scaleVis, largura automática via viewBox) e documente
      a escolha em comentário pt-BR — o que importa é tamanho ∝ sqrt(fat).
      Dentro do svg: viewBox com pad (estilo CityGauge), leito
      `rgba(255,255,255,0.04)`, preenchimento SÓLIDO `fill={i.cor}` `fillRule="evenodd"`,
      e contorno `stroke={i.cor}` com glow (feDropShadow, floodColor={i.cor}). IDs de
      filtro únicos por polo (slug do nome) para não colidir entre svgs.
    - SE shape == null (fallback): desenhar um marcador simples — um `<svg>` com um
      círculo (ou quadrado arredondado) `fill={i.cor}` cujo diâmetro = `maxHeight*scaleVis*0.7`,
      mesmo glow/contorno, alinhado pela base. Comentário pt-BR explicando o fallback.
    - Alinhamento pela base: usar um wrapper flex com `items-end` na linha de cidades,

      junto da maior). A label fica abaixo, fora do alinhamento de base.
    - Label sob cada cidade: `formatCurrency(i.faturamento)` (branco, semibold, tabular-nums)
