<objective>
Corrigir o bug "cadastro de usuários não dá feedback de erro" em `resources/js/Pages/Users/Index.jsx`.

**Causa raiz (já diagnosticada — NÃO reinvestigar):** o componente destructura `errors` de `useForm()`, mas o submit em [Users/Index.jsx:113-114](resources/js/Pages/Users/Index.jsx#L113) usa `router.put()` / `router.post()` (router global do Inertia) em vez de `form.put()` / `form.post()`. O `errors` do `useForm` local só é populado quando o próprio form submete via `form.*`; com `router.*`, os erros chegam em `usePage().props.errors` (shared prop automática). Resultado: `errors` no escopo do componente fica sempre `{}`, o `<FormErrorBanner>` não renderiza, `{errors.password && ...}` não renderiza, `onSuccess` não dispara, modal fica preso "sem feedback".

**Sintoma específico:** payload `{password: "fgb4352345", password_confirmation: ""}` → regra `confirmed` em [UserController.php:159](app/Http/Controllers/UserController.php#L159) rejeita → 302 com `errors.password = "validation.confirmed"` → erros invisíveis na UI.

- **AUDIT (apenas listar, NÃO corrigir):** grep estruturado em `resources/js/Pages/` para identificar outras páginas com o mesmo antipadrão (errors de useForm + submit via `router.*`). Documentar achados no SUMMARY.md como follow-up.

Shared prop do Inertia (injetada por `HandleInertiaRequests`):
- `usePage().props.errors` → `{ [key: string]: string }` — populado automaticamente após qualquer redirect 302 com `withErrors()` ou `ValidationException`, INDEPENDENTE de quem submeteu (form local ou `router` global).

Hook `useForm` do Inertia:
- `const { data, setData, processing, reset, errors } = useForm(initial)`
- `errors` aqui SÓ é populado quando o submit acontece via `form.post() / form.put() / form.patch() / form.delete() / form.submit()`.
- Quando o submit usa `router.post()` etc., o hook não observa a resposta → `errors` permanece `{}` para sempre.

Submit atual em Users/Index.jsx (linhas 113-114, NÃO mexer):
```
if (editing) router.put(route('users.update', editing.id), payload, opts);
else router.post(route('users.store'), payload, opts);
```

Componente FormErrorBanner ([resources/js/Components/FormErrorBanner.jsx](resources/js/Components/FormErrorBanner.jsx)):
- Assinatura: `<FormErrorBanner errors={errors} />`
- Renderiza `null` quando `errors = {}`. Renderiza box vermelho com lista quando há erros. Já funciona corretamente — não tocar.

UserController validação ([app/Http/Controllers/UserController.php:141-160](app/Http/Controllers/UserController.php#L141)):
- `password: ['required', 'string', 'min:8', 'confirmed']` (store) / `['nullable', ...]` (update)
- `confirmed` exige que `password_confirmation` exista e seja igual a `password`.
- Falha → `ValidationException` → 302 + `errors` na shared prop.
